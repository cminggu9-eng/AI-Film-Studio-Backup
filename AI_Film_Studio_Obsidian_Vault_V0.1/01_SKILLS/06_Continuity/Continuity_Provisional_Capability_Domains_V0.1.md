# Continuity Provisional Capability Domains V0.1

The labels below are discovery labels, not a final Capability Model. Their scope may be merged, split, renamed or supplemented only after verified evidence supports a change.

| ID | Provisional domain | Phase-1 boundary |
| --- | --- | --- |
| CT-C01 | Canon / Locked Fact Preservation | Detect and cite possible conflict; Showrunner decides Canon. |
| CT-C02 | Entity Identity Continuity | Track identity references without inventing identity facts. |
| CT-C03 | Character Knowledge-State Continuity | Separate character knowledge, belief, misinformation and audience knowledge. |
| CT-C04 | Character Relationship-State Continuity | Observe relationship temperature; never create a numeric trust model. |
| CT-C05 | Temporal Continuity | Compare chronology, elapsed time, dates, day/night, travel and recovery only when evidenced. |
| CT-C06 | Causal Continuity | Test whether an observed result follows an authorized cause or explanation. |
| CT-C07 | Scene-to-Scene State Transition | Compare ending state to next entry state; do not demand literal sameness. |
| CT-C08 | Location / Spatial Fact Continuity | Track known location, position and connectivity facts; never design space. |
| CT-C09 | Entry / Exit / Presence Continuity | Test presence and lawful off-screen transitions. |
| CT-C10 | Object / Prop Possession Continuity | Track evidenced possession, owner and location; Art Director owns design. |
| CT-C11 | Object / Prop Condition Continuity | Track condition and change, not object styling or dramatic function. |
| CT-C12 | Costume / Appearance State Continuity | Track evidenced wear, dirt, blood, damage and changes; no redesign. |
| CT-C13 | Injury / Physical Condition Continuity | Track depicted side, severity, mobility, dressing, fatigue and recovery; no diagnosis. |
| CT-C14 | Environment / Set-State Continuity | Track evidenced condition and changes; no set design. |
| CT-C15 | Performance-State Continuity | Track playable carry such as fatigue, tension, confidence and relation temperature; no acting instruction or linear-emotion mandate. |
| CT-C16 | Dialogue / Fact Reference Continuity | Flag conflicting references or knowledge leakage; never rewrite dialogue. |
| CT-C17 | Screen Direction / Action Continuity Boundary | Preserve continuity-relevant action/spatial facts; Director retains staging, camera and coverage. |
| CT-C18 | Information Reveal / Knowledge Timing Continuity | Check authorized information flow without writing story. |
| CT-C19 | Change Authorization / State Mutation Legality | Ask what evidence makes a change lawful; do not create an authority schema. |
| CT-C20 | Contradiction Detection | Identify a material conflict candidate and cite both sides. |
| CT-C21 | Contradiction Classification / Severity | Explore categories and impact; final labels are deferred. |
| CT-C22 | Source-of-Truth / Authority Resolution | Identify source and lawful owner; no runtime precedence decision. |
| CT-C23 | Continuity Handoff / Ownership Routing | Route an issue to the responsible role without directing the fix. |
| CT-C24 | Continuity Record / State Snapshot Logic | Define what a future snapshot may need conceptually; no columns, schema or tracker. |
| CT-C25 | Intentional Discontinuity / Allowed Exception | Allow authorized dream, memory, montage, nonlinear, stylized or unreliable treatment. |
| CT-C26 | Retcon / Canon-Change Boundary | Detect a possible retcon; Showrunner alone resolves Canon change. |
| CT-C27 | Uncertainty / Missing-State Handling | Mark unavailable evidence rather than infer a contradiction. |
| CT-C28 | Anti-Overcorrection / False Positive Control | Require evidence, scope and owner before raising a material concern. |
| CT-C29 | Cross-Department Continuity Interface | Compare state across departments without becoming their manager. |
| CT-C30 | Future Runtime / Continuity Database Boundary | `DEFERRED / FUTURE CONTINUITY DATABASE INTERFACE`; no architecture is defined. |

## Provisional clusters

1. **Authority and evidence** — CT-C01, 19–23, 25–28.
2. **Narrative state** — CT-C02–07, 16, 18, 26–27.
3. **Embodied and visible state** — CT-C08–15, 17.
4. **Record/interface boundary** — CT-C24, 29–30.

## Known discovery gaps

The candidate bodies are strongest on physical/on-set continuity, timing, dialogue, props and appearance. Character knowledge, reveal timing, retcon distinction, authorization legality, classification/severity and anti-overcorrection require verified source supplementation before a final model is possible.
