# Continuity Output Model V0.1

## Minimum sufficient output

Use only the elements needed by the current judgment:

| Output element | Purpose |
| --- | --- |
| Reviewed Fact / State | What was actually examined. |
| Relevant Prior State | Cited baseline, if comparison needs one. |
| Current / Proposed State | Cited state/difference under review. |
| Continuity Judgment | One Phase 4 primary outcome. |
| Evidence / Source Basis | Locators and concise evidence summary. |
| Transition Basis | Traceable event, time, context, or exception when applicable. |
| Uncertainty / Missing Context | Narrow essential unknown or ambiguity, if present. |
| Materiality | Concise relevance to protected continuity concern; never severity tier. |
| Owner / Handoff | Lawful resolution owner and bounded question/flag, if needed. |
| Updated Current State | Only an authorized/supplied reference update; no self-created Canon/state. |

The model does not force every element every time. It does not output a repaired screenplay, visual redesign, staging plan, performance direction, or private chain-of-thought. It may provide concise evidence, comparison summary, conflict explanation, outcome, and handoff.
