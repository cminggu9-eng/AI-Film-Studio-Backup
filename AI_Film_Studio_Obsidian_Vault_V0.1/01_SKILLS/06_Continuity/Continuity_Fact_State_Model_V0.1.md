# Continuity Fact / State Model V0.1

All labels below are capability vocabulary, not database fields or Runtime tokens.

| Concept | Model meaning | Continuity treatment |
| --- | --- | --- |
| LOCKED FACT | Locatable fact constrained by a Showrunner lock or equivalent authorized source. | Preserve; cite possible conflict; Showrunner resolves. |
| CURRENT STATE | Evinced present condition relevant to the reviewed continuity question. | Compare only named, decision-relevant dimension. |
| CHARACTER KNOWLEDGE | Information a character has a supported access path to obtain, witness, receive, or otherwise know. | Do not infer from audience exposure alone. |
| CHARACTER BELIEF | What a character takes to be true without confirmed story truth. | Preserve as belief; do not promote to Canon. |
| CHARACTER CLAIM | A statement made by a character. | May be true, false, mistaken, deceptive, or incomplete; not automatically Canon. |
| AUDIENCE KNOWLEDGE | Information made available to the viewer through presentation. | Keep separate from character knowledge. |
| DESIGN / PERFORMANCE INTERPRETATION | An owner-domain creative choice about visual/performance realization. | May supply observed state only; Continuity cannot direct it. |
| MISSING INFORMATION | Essential comparison evidence is absent. | Use CONTEXT INSUFFICIENT, not contradiction. |
| AMBIGUOUS INFORMATION | More than one reading remains compatible with supplied evidence. | Preserve ambiguity / route essential question; do not choose fact. |
| AUTHORIZED OR SUPPORTED CHANGE | Difference with a traceable event, elapsed time, upstream decision, or other legitimate supplied basis. | Allow/annotate; do not turn into a repair instruction. |
| INTENTIONAL DISCONTINUITY | Specific supplied marker/context supports deliberate nonmatching presentation. | Preserve exception; no automatic error or self-authorization. |
| CONTRADICTION | Applicable locatable evidence establishes incompatible state for the same context after change/exception/context tests. | Distinguish potential from confirmed; flag/handoff only. |

## Significant state filter

State is relevant only when it can affect a later fact, causality, comprehension, knowledge legality, scene legality, visual/performance continuity, or cross-department consistency. Minor detail does not become permanent Canon by default.

The model supports qualitative relationship/performance carry only within evidence. It creates no relationship score, trust meter, emotional state machine, medical model, or entity-merge heuristic.
