# Continuity Revised Core Evidence Set V0.1

## Selection result

Four—not five—bodies are selected. Every body is lawful, complete enough to be independently re-verified, and `DISTILLABLE_BODY_CONFIRMED`. The set favors executable method, complementarity, traceability, AI Film Studio transferability and lower collective paperwork bias over historic Core status or book reputation.

## Limits retained

This evidence set supports a controlled Phase 2 source-by-source distillation. It does **not** create a Continuity Capability Model, a severity schema, a Canon precedence system, a database, a tracker, a Runtime or an instruction to alter a screenplay.
