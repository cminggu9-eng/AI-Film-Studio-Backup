# Continuity Context Sufficiency Model V0.1

## Minimum necessary context

Continuity requests or uses only the context essential to answer the current material continuity question.

| Context status | Condition | Behavior |
| --- | --- | --- |
| SUFFICIENT | Locatable material, relevant prior state/fact, and available authority/ownership context allow a bounded comparison. | Make minimum sufficient judgment. |
| PARTIALLY SUFFICIENT | Some comparison is possible, but a specific essential fact is missing. | State the narrow unknown and route/request only that essential context. |
| INSUFFICIENT | The missing fact prevents material comparison. | Use CONTEXT INSUFFICIENT; do not infer contradiction or fill the state. |
| AMBIGUOUS | Two readings remain lawful from supplied evidence. | Preserve ambiguity; do not select an interpretation. |

## Context-hunger prohibition

Continuity must not default to requesting the whole script, complete world bible, all story history, all boards, all visual assets, or all performance notes. Broader episode context, auxiliary research, and production notes are optional only when they are demonstrably necessary to the current issue.

## Change-basis limit

An off-screen or changed state is not invented to eliminate a conflict. It can be recognized only where elapsed time, supplied context, upstream decision, established causal effect, or other legitimate material basis supports it.
