# Continuity Risk Audit V0.1

| Risk | Control |
| --- | --- |
| RISK-CT-01 Intentional discontinuity false error | Require upstream authorization/context for dream, memory, montage, nonlinear, stylized, comic or unreliable treatment before flagging. |
| RISK-CT-02 Character belief vs Canon | Keep belief, statement and locked fact distinct; route Canon conflict to Showrunner. |
| RISK-CT-03 Audience knowledge leak character knowledge | Track audience and character knowledge separately; do not infer access from audience exposure. |
| RISK-CT-04 Time passage ignored | Check explicit or authorized elapsed time, travel and recovery before asserting a mismatch. |
| RISK-CT-05 Legal offscreen change rejected | Accept an evidenced off-screen transition; do not require every change to be shown. |
| RISK-CT-06 Performance variation false contradiction | Treat performance as contextual and playable, not as a frozen emotional pose. |
| RISK-CT-07 Costume redesign vs state confused | Track state/condition only; Art Director owns design changes. |
| RISK-CT-08 Prop identity vs similar prop | Require identity evidence before treating a similar object as the same prop. |
| RISK-CT-09 Dialogue lie Canon conflict | Classify a line as a possible lie, belief, error or perspective before escalating. |
| RISK-CT-10 Retcon detection equals retcon authority | Detect and hand off; only Showrunner may authorize a Canon change. |
| RISK-CT-11 Minor cosmetic issue becomes major Canon | Match escalation to material impact and evidence; no final severity scale is fixed in Phase 1. |
| RISK-CT-12 Continuity fixes Scene Writer | Flag/location/evidence/handoff only; Scene Writer owns rewriting. |
| RISK-CT-13 Continuity takes Director staging authority | Preserve factual spatial/action evidence only; no blocking, camera or coverage instruction. |
| RISK-CT-14 Continuity takes Art Director design authority | Track visual state, never redesign props, costume, set or environment. |
| RISK-CT-15 Continuity takes Character & Acting | Track carry conditions, never prescribe performance. |
| RISK-CT-16 Premature database architecture | CT-C30 remains a future interface boundary; no schema, tracker or implementation. |
| RISK-CT-17 Missing context false contradiction | Mark `UNKNOWN`/missing state and request lawful evidence instead of guessing. |
| RISK-CT-18 Ambiguity false error | Preserve ambiguity where the source allows it; distinguish “not proved” from “contradicted.” |
| RISK-CT-19 Nonlinear narrative chronological error | Evaluate story order and presentation order separately when authorized. |
| RISK-CT-20 State tracking excessive bookkeeping | Record only decision-relevant state; never turn every observable detail into a required ledger. |

Risk status: all controls are discovery-level safeguards. They are not operational rules or a finalized severity system.
