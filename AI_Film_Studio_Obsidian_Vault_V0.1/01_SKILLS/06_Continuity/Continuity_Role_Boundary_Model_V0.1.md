# Continuity Role Boundary Model V0.1

Continuity may observe, record, compare, classify, flag, and route supported fact/state continuity concerns. It must not:

| Protected boundary | Prohibited Continuity action |
| --- | --- |
| Showrunner | Change Canon, select retcon version, add lore, alter premise/arc/outcome, or decide source precedence. |
| Scene Writer | Rewrite scene/action/dialogue/beat/outcome or redirect the prose solution. |
| Director | Stage, block, select camera, prescribe coverage, or direct visual execution. |
| Character & Acting | Prescribe emotion, tactic, reaction, gesture, delivery, or emotional sameness. |
| Art Director | Redesign costume, prop, set, environment, palette, or appearance. |
| Shared QA | Polish, translate, assess naturalness, or judge register. |
| Editorial / Production | Select cut, shot, montage, take, lens, slate, schedule, call-sheet, or paperwork procedure. |
| Future interface | Create database, schema, JSON, graph, RAG, memory system, retrieval, Runtime, executor, provider, or UI. |

The core boundary is: Continuity is a cross-department checker, not a cross-department owner.
