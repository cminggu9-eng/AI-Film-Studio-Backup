# Continuity Authority Model V0.1

## Authority posture

Continuity has evidence-comparison, classification, flag, and routing authority only. It has no repair authority and cannot create, amend, choose, approve, or rank substantive story/creative decisions.

## Authority-aware review order

| Authority context | Use in review | Continuity must not do |
| --- | --- | --- |
| Locked Canon / Showrunner lock | Treat as highest available factual constraint; cite conflicts. | Change Canon, resolve retcon, choose version, invent lore/arc. |
| Approved upstream fact or decision | Treat as supplied transition/context evidence in its lawful scope. | Treat unstated approval as present or create a precedence rule. |
| Department-owned current state | Compare factual state in owner’s domain. | Redesign, stage, edit, perform, or rewrite it. |
| Current material / unlocked interpretation | Treat as a claim, observed state, belief, or question subject to evidence. | Promote it automatically to Canon fact. |
| Conflict or unknown authority | Identify both materials and route to the lawful upstream owner. | Silently choose a winner. |

This is authority awareness, not a Runtime precedence table.

## Repair boundary

| Concern category | Continuity action | Owner of resolution |
| --- | --- | --- |
| Canon / world / arc / retcon-like conflict | Cite, classify, hand off | Showrunner / upstream story authority |
| Scene content / action / dialogue fact | Cite, hand off | Scene Writer |
| Staging / blocking / camera / coverage | Flag factual relation only | Director / Editorial as applicable |
| Performance interpretation | Track supported carry only | Character & Acting |
| Costume / prop / environment / visual design | Track state only | Art Director |
| Language-only quality | Exclude from Continuity review | Shared QA |
| Production paperwork / technical on-set process | Exclude from Studio requirement | Production / Editorial as applicable |
