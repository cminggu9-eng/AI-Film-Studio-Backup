# Continuity Input Model V0.1

This is a capability-level intake model, not a Runtime schema, JSON contract, or retrieval policy.

| Input tier | Minimum content / use |
| --- | --- |
| REQUIRED | Material under review; relevant prior established fact/state; available authority/ownership context. |
| USEFUL | Preceding/following scene state; Showrunner lock; Director, Character & Acting, or Art Director state when directly relevant; time/location markers; prop/costume/injury reference. |
| OPTIONAL | Broader episode context, auxiliary research, or extra production notes only if a specific current question requires them. |

## Intake rules

- Identify the question and named continuity dimensions first.
- Request only minimum necessary context for that question.
- Treat supplied claims, beliefs, and interpretations as non-Canon unless locatable authority/evidence supports them.
- Absence of nonessential material must not block a bounded judgment.
- Absence of essential material yields CONTEXT INSUFFICIENT, not an invented state or error.
