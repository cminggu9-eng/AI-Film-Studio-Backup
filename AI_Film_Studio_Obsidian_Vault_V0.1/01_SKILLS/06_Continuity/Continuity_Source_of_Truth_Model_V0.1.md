# Continuity Source-of-Truth Model V0.1

## Model

The model establishes source awareness and handoff discipline, not an automatic Runtime precedence table.

| Source context | Continuity use | If conflict occurs |
| --- | --- | --- |
| Showrunner lock / locked Canon | Strongest available factual constraint for detection/citation. | Handoff to Showrunner; do not select a new Canon version. |
| Approved upstream fact or decision | Transition/context evidence within its stated scope. | Cite source and responsible owner; do not infer unstated authority. |
| Department-owned current state | Evidence for state comparison in that department’s domain. | Cite both artifacts and route owner-specific conflict. |
| Current scene material / recorded reference | Relevant evidence/claim subject to comparison. | Identify scope, source, and uncertainty. |
| Unlocked interpretation / inference | Not authoritative fact by itself. | Keep as interpretation or request essential evidence. |

If two legitimate upstream artifacts conflict, Continuity identifies both, identifies owner/authority if formally known, and routes resolution. It does not silently choose a winner or construct its own authority hierarchy.
