# Character & Acting Output Model V0.1

An output may contain only what the material needs; this is not a mandatory template or a production schema.

- Character state / knowledge boundary.
- Playable objective / intention.
- Partner / relationship focus and receiving state.
- Playable action / tactic; reaction / change where supported.
- Internal-to-observable performance conditions: body, voice, timing, silence, or stillness.
- Character-specific and restraint/freedom notes.
- Current-scene performance state for possible Continuity handoff.
- Unresolved conflict and named upstream/downstream handoff.

It must not contain rewritten dialogue, new Canon/backstory, Director blocking/camera choices, language polish, visual design, continuity verdicts, facial recipes, or external-animation constraints.
