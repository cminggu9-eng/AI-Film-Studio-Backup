# Character & Acting Input Model V0.1

| Class | Inputs | Sufficiency rule |
| --- | --- | --- |
| Required | Character identity; lawful character facts; knowledge state; scene text/material; locked objective/resistance/turn/outcome where supplied; interaction partners. | Block only when a material fact, knowledge, objective, outcome, relationship, or staging conflict makes performance interpretation indeterminate. |
| Useful | Relationship state; prior emotional/physical state; Director staging notes; environment facts; relevant prop/physical constraints; approved performance history. | Use when present; do not fabricate when absent. |
| Optional | Visual references; voice references; downstream technical constraints; future external animation constraints. | Their absence must not cause context hunger. |

No childhood trauma, personality type, full psychology history, or micro-expression specification is required context.
