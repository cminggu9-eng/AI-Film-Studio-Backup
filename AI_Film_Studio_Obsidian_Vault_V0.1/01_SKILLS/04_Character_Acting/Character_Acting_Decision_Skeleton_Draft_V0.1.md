# Character & Acting Decision Skeleton Draft V0.1

1. Verify Character / knowledge / text / locked-fact boundary (CA-DR01).
2. Read literal circumstances, immediate want, and playable action (D01–D03, D13–D14).
3. Identify partner/relationship conditions and what has actually been received (D05, D10–D12, D16).
4. Choose a bounded response path: action, change, delay, concealment, silence, or stillness (CA-DR05/09).
5. Consider body, voice, timing, and physical behavior only as conditional responsive channels (D06–D09; CA-DR08).
6. Preserve character specificity and performer discovery; reject stereotypes and result/micro-management (D04, D13, D17–D18).
7. Emit only a scene-local performance interpretation; flag/handoff text, Canon, Scene Writer, Director, QA, or Continuity issues.

This is a Phase 4 input draft, not a Capability Model, Mode system, Primary State model, Runtime token set, schema, or output envelope.
