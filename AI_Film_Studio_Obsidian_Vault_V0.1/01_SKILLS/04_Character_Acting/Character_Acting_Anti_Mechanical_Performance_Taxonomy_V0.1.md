# Character & Acting Anti-Mechanical Performance Taxonomy V0.1

An action is not inherently wrong. The failure condition is `UNMOTIVATED`, `GENERIC`, `REPETITIVE`, `PRE-RECEIVED`, `RESULT-FORCED`, or `CHARACTER-UNSPECIFIC`.

| Pattern | Failure condition | Safe evaluation route |
| --- | --- | --- |
| Sigh / lip bite / fist clench / head lower / eyebrow or eye flicker | Used as an automatic emotion substitute. | Ask whether current action, received stimulus, Canon, and character specificity support it; never prescribe its facial mechanics. |
| Gesture with every line / constant physical business | Visibility is substituted for live performance. | Stillness or a delayed/non-visible response is permitted. |
| Sad smile / gaze / pause reused across characters | Same behavior is treated as universal. | Retain multiple bounded hypotheses and personal route. |
| Emotional push without stimulus | Result is played before an actual circumstance/partner input. | Restore playable process and receive/change/respond. |
| Preplanned reaction | Performer selects output before reception. | Reopen partner/situation attention. |
| Voice decoration | Sound has no intention, relationship, or response function. | Keep voice conditional on current performance state. |
| Second-by-second behavior commands | Direction becomes micro-management. | Use a bounded playable question/adjustment or handoff. |

No facial dictionary, numerical intensity scale, psychology diagnosis, or animation/motion control is created.
