# Character & Acting Capability Stack V0.1

| Layer | Capability | Evidence / final rule support |
| --- | --- | --- |
| L1 | Lawful performance context: character fact, knowledge, given circumstance, locked scene material. | D01/D15/D18; CA-DR01. |
| L2 | Playable intention: want, action, process rather than bare result. | D02/D03/D13/D14; CA-DR04. |
| L3 | Partner / relationship / receiving: attention to what is actually available. | D05/D10/D11/D16; CA-DR05. |
| L4 | Response and change: tactic, delay, concealment, withdrawal, escalation, or stillness. | D05/D11/D16; CA-DR05/09. |
| L5 | Observable performance channels: body, voice, timing, silence, proximity, object relation, attention. | D06–D09/D15; CA-DR08. |
| L6 | Character specificity, restraint, anti-mechanical control, and performer freedom. | D04/D13/D17/D18; CA-DR06/07/09. |
| L7 | Authority check and handoff. | D09/D14/D17; CA-DR01–03/10. |

The stack is seven layers because it follows the existing evidence architecture; it is not a copied ten-layer template.
