# Character & Acting Provisional Capability Domains V0.1

These are discovery axes, not a Capability Model. They may be merged, split, renamed, removed, or added only through later source-supported work.

| ID | Provisional domain | Discovery question |
| --- | --- | --- |
| CA-C01 | Character / Canon Preservation | How is a lawful character state performed without inventing biography, knowledge, or arc? |
| CA-C02 | Given Circumstances & Knowledge State | What known circumstances constrain playable behavior? |
| CA-C03 | Objective / Intention | What does the character want now? |
| CA-C04 | Playable Action / Tactic | What can the performer do to pursue that objective? |
| CA-C05 | Listening / Reaction | How does the performer receive, process, change, and respond? |
| CA-C06 | Subtext / Inner Intention | How can unsaid intention be carried through action, timing, reaction, behavior, and delivery? |
| CA-C07 | Emotional State & Transition | How does an emotional state emerge from circumstances and change rather than from a label preset? |
| CA-C08 | Internal State to Observable Performance | How may inner state become playable, observable behavior? |
| CA-C09 | Physical Behavior / Gesture | How can posture, movement, stillness, effort, proximity, avoidance, and object interaction serve the scene? |
| CA-C10 | Facial Expression / Micro-Expression Boundary | How can visibility and concealment be addressed without facial recipes or pseudo-science? |
| CA-C11 | Voice / Speech Delivery | How do tempo, pause, interruption, hesitation, emphasis, vocal intention, and speech action serve existing words? |
| CA-C12 | Timing / Pause / Performance Rhythm | How can reaction timing and silence serve performance without claiming editorial or directorial rhythm? |
| CA-C13 | Relationship / Status / Power Dynamics | How do relationship and status affect playable interaction? |
| CA-C14 | Performance Beats / Scene Turn Response | How does performance respond to a Scene Writer turn without changing it? |
| CA-C15 | Character-Specific Behavioral Signature | How can performance avoid generic AI acting clichés and remain character-specific? |
| CA-C16 | Restraint / Scale / Intensity Control | How can scale be adjusted lawfully across stage and screen contexts? |
| CA-C17 | Actor Freedom / Anti-Overdirection | How can playable intention preserve bounded freedom rather than micro-commanding every moment? |
| CA-C18 | Director / Blocking Collaboration | How are performance needs surfaced while preserving Director blocking/staging authority? |
| CA-C19 | Performance State Handoff / Continuity Boundary | How is scene-local state handed off without claiming Continuity authority? |
| CA-C20 | Anti-Mechanical / Anti-Cliché Performance | What prevents emotion decoration, repetitive gesture, and template behavior? |
| CA-C21 | External Animation / Motion / AI Performance Constraint Boundary | `FUTURE INTERFACE BOUNDARY` only; no AI/motion rule is created in Phase 1. |

## Non-Negotiable Discovery Risks

- Emotion label does not equal facial preset.
- Theatre method does not automatically equal screen rule.
- Subtext must not be written into dialogue.
- Physical behavior must not be assigned mechanically to every line.
- Character & Acting must not create AI/animation constraints before a real production technology stack exists.
