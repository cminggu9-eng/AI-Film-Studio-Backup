## Planned order and stop rule

1. Resolve lawful access and licence constraints first.
2. Distill individual sources independently with source / inference separation.
3. Audit coverage and overlap after each individual source.
4. Seek a targeted source only for a recorded gap; do not expand candidates for prestige.
5. Stop and request user authorization before any cross-distillation, capability model, production skill, Runtime, executor binding, or provider action.

## Candidate recommendation

- **Core candidates / source groups:** DR-CA-01 DGA long-form Q&A pool; DR-CA-02 Belli / Rooney; DR-CA-03 Weston; DR-CA-04 Sundance Core Elements.
- **Reserve candidates / source groups:** DR-CA-05 DGA Visual History pool; DR-CA-06 Jeremy Podeswa blocking highlight.
- **Excluded:** DR-CA-07 Rodriguez third-party archive, DR-CA-08 migrated / unstable BAFTA page, DR-CA-09 cinematography-only materials as sole Director authority, DR-CA-10 blogs / quote collections / AI summaries / unlicensed scans.

The core set is four source groups, not a mechanically fixed “five directors”; it is deliberately limited to keep later cross-distillation tractable.
