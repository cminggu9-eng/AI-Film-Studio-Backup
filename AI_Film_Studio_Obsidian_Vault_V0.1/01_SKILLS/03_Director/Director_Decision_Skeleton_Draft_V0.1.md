# Director Decision Skeleton Draft V0.1

## Status

This is a Phase 4 input scaffold only. It is not frozen, executable, a shot-list generator, or a Capability Model.

```text
Assigned Story / Scene Intent
  → Authority and material-event check
  → Audience information state
  → Spatial geography and playable blocking need
  → Visual emphasis / position / movement purpose
  → Coverage and performance access
  → Rhythm / transition-function condition
  → Production burden and adaptive collaboration
  → Bounded handoff record
```

| Step | Director question | Phase 3 evidence | Required limit / handoff |
|---|---|---|---|
| 1. Authority check | What Story Intent, Scene Function, outcome, facts, and material dramatic event are locked? | D01, D09 / R01 | No rewrite; escalate conflict to Showrunner / Scene Writer. |
| 2. Audience state | What should the audience notice, defer, understand spatially, or experience now? | D01, D07–D10, D16 / R01, R05–R06 | No invented story information. |
| 3. Geography / blocking | What relation, access, position, sightline, movement, and playable turn must remain legible? | D02, D04, D06–D07, D11, D13, D15 / R03–R04, R09 | DP/Art/Continuity receive needs, not a technical or Canon system. |
| 4. Visual purpose | Why position, composition, movement, distance, reveal, or concealment here? | D03, D08, D16 / R02, R05 | DP retains technical realization; no display-only choice. |
| 5. Coverage / performance | What material is needed for performance, information, relation, and alternatives without template repetition? | D05–D06, D11–D14 / R03–R04, R08 | Character & Acting retains method; Editor retains post methodology. |
| 6. Rhythm / transition condition | Is this a turn, major emotional event, or transition, and what visual scale/resource condition follows? | D09–D10 / R06–R07 | No Editor takeover and no DR-C14 entry/exit invention. |
| 7. Burden / adaptation | What is required, what is optional if time permits, and does a new proposal improve the same purpose? | D04, D07, D10, D12, D15 / R07, R09–R12 | Production owns cost/schedule; departments supply means. |
| 8. Handoff | Which intent, spatial, practical, or continuity implication needs a bounded downstream handoff? | D01–D02, D04, D07, D12, D15 | No ownership transfer beyond Director authority. |

`DR-C14 = NO EVIDENCE / NOT DISTILLABLE`; `DR-C20 = DEFERRED / FUTURE EXTERNAL PRODUCTION CONSTRAINT INTERFACE`.
