## Architecture

- Capability Stack: 9 evidence-supported layers; no artificial tenth capability.
- Decision Flow: lock → intent/information → geography/blocking → visual/camera/coverage → rhythm → burden → handoff.
- Authority Priority: 8 ordered constraints, with Canon / locks above preference.
- Context Sufficiency: blocks only essential scene-level factual/authority uncertainty, never missing lens, palette, or acting detail.

## Inputs / outputs

- Input Model: REQUIRED, USEFUL, and OPTIONAL categories; no context hunger.
- Output Model: intent, staging/blocking, audience information, geography, camera/coverage intent, rhythm/transition intent, burden, and handoffs.
- Modes: `PLAN`, `REVISE`, `DIAGNOSE`.
- Primary States: `DIRECTION_PLAN_PRODUCED`, `DIRECTION_PLAN_REVISED`, `NO_MATERIAL_DIRECTION_CHANGE`, `NEEDS_CONTEXT`, `UPSTREAM_DECISION_REQUIRED`, `OUT_OF_SCOPE_HANDOFF`.
- Handoff Model: upstream for locks/Canon/Scene Function; downstream for specialist authority.
