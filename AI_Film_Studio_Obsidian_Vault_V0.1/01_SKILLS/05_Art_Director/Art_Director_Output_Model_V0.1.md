# Art Director Output Model V0.1

This is a capability-level output model, not a Runtime schema. It requires minimum-sufficient output: only categories relevant to the decision are emitted.

| Output category | Minimum content | Limit |
| --- | --- | --- |
| A. Visual Fact / Canon Lock | Applicable fact classes, source/authority, and unresolved conflict. | Never rewrite Canon or promote an interpretation into fact. |
| B. Story / Design Intent | The lawful story/world/character/function need and visual response rationale. | No scene rewrite, new event, or new object meaning. |
| C. Research Basis | Source hierarchy, contextual reading, and bounded interpretation. | No unverified fact or reference copying. |
| D. World / Environment Logic | Function, use, history, access/restriction, condition, and physical-world logic where supported. | No new lore, culture, religion, technology, or history. |
| E. Visual Hierarchy | Primary, supporting, ordinary, quiet, dense, or sparse role as relevant. | No universal template or hero treatment for every space. |
| F. Color / Material System | Relational color, material, surface, form, density, and coordination decision. | No deterministic color/material/shape/class/culture dictionary. |
| G. Character Visual Identity | Lawful silhouette, accessories, wear, material, and differentiation information. | No psychology, trauma, arc, or hidden history inference. |
| H. Costume / Appearance | Period, world fit, use, movement, authorized status, progression, and physical usability. | Character & Acting retains performance; no fashion-only styling mandate. |
| I. Prop / Object Logic | Function, ownership, world fit, history, wear, use, recognition, and dramatic requirement. | Do not alter Scene Writer object meaning or required function. |
| J. Graphics / Motif if relevant | Bounded in-world graphic coherence or restrained supported recurrence. | No graphic-design specialty system or symbolism engine. |
| K. Department Cohesion | Coordination decision across relevant departments and retained execution owners. | No Director, DP, C&A, Continuity, or Production takeover. |
| L. Reference Principles | Transferable principle, research role, and copy-risk record. | Never copy signature production design, franchise set, iconic costume, prop, or visual identity. |
| M. Production Burden | Asset/build/costume/prop/sourcing/maintenance/repeatability/location signal and lawful alternatives. | Production retains final feasibility decision. |
| N. Current Visual State | Current costume, wear, dirt, damage, prop, set, environment, or transformation state. | Continuity owns cross-scene tracking, validation, and correction. |
| O. Handoffs / Unresolved Issues | Owner, exact issue, protected constraint, and requested decision. | Do not absorb the receiving role's decision. |

No output category contains positive or negative prompts, image-model parameters, Stable Diffusion, Midjourney, Flux, ComfyUI nodes, model IDs, sampling values, or other visual-production syntax.
