# Art Director Risk Audit V0.1

| Risk | Control |
| --- | --- |
| RISK-AD-01 Prompt beautifier | Require lawful visual-story purpose and design rationale; reject adjective-only output. |
| RISK-AD-02 Style over story | Story/Canon precedence; flag rather than redesign plot. |
| RISK-AD-03 Generic AI tropes | Evidence-led specificity; no trend keyword substitution. |
| RISK-AD-04 Style mixing | One traceable visual-system rationale; flag incoherent references. |
| RISK-AD-05 Color psychology | No universal emotion-to-color rule without source and context. |
| RISK-AD-06 Symbolism overload | Motifs remain conditional and story-serving. |
| RISK-AD-07 Overdesigned environments | Environment serves playable/dramatic use, not spectacle. |
| RISK-AD-08 Random clutter | Every prop/dressing choice needs lawful visual or functional rationale. |
| RISK-AD-09 Reference copying | References inform constraints, never copy protected designs. |
| RISK-AD-10 Cultural/period mashup | Primary/institutional research provenance and explicit uncertainty. |
| RISK-AD-11 Director takeover | No staging, camera, coverage, or attention decision. |
| RISK-AD-12 DP takeover | No lens/exposure/lighting-ratio/optical execution. |
| RISK-AD-13 C&A takeover | Appearance only; no psychological/performance facts. |
| RISK-AD-14 Continuity takeover | Current-scene state handoff only. |
| RISK-AD-15 Production burden | Flag asset/build/crowd/material burden; Production decides. |
| RISK-AD-16 Costume disconnection | Tie appearance to lawful world/character facts and feasibility. |
| RISK-AD-17 Decorative props | Preserve Scene Writer object function and meaning. |
| RISK-AD-18 Department disagreement | Record alternatives/constraints and route to lawful owner. |
| RISK-AD-19 AI homogenization | No model-style default, trend imitation, or generated-image assumption. |
| RISK-AD-20 Premature ComfyUI / AI | AD-C25 remains deferred interface; no workflow syntax. |

Risk status: all controls are discovery-level requirements, not operational rules.
