# Art Director Studio-Native Rules Draft V0.1

These are Phase 3 drafts only. Promotion is reserved for a later Capability Model phase.

| Rule | Class | Origin AD-D / relationship | Draft rule / conditions | AD-C / boundary |
| --- | --- | --- | --- | --- |
| AD-DR01 | HARD | 05,09–11 / R02,R03 | Preserve lawful visual facts; label evidence, interpretation, and approved stylization rather than using design coherence to rewrite Canon. | C01,15,23; Showrunner/Scene Writer retained. |
| AD-DR02 | HARD | 05–06,09–11 / R11 | Translate references into transferable principles and traces; do not copy a protected visual identity or use an unverified reference as fact. | C15,23,24; no reference copying. |
| AD-DR03 | HARD | 04,12,16,20 / R06 | Art Director supplies visual-world response and handoff, never Director staging/camera or DP optical execution; Production and Continuity retain their final authority. | C17–22; role boundaries. |
| AD-DR04 | DEFAULT | 01,17–18 / R01 | Every major design choice states the lawful story/world/character/function need it serves before aesthetic treatment. | C01–04,24; no style-first pipeline. |
| AD-DR05 | DEFAULT | 05,09–11 / R02,R11 | Convert research into a recorded design decision: source hierarchy → contextual reading → bounded design response. | C01,03,08–10,15,23. |
| AD-DR06 | DEFAULT | 03,06,15 / R05 | Maintain one explicit visual concept and communicate it in fit-for-purpose artifacts, references, layouts, samples, or briefs. | C04–08,12–13,17,23; no final schema. |
| AD-DR07 | DEFAULT | 02,14,18 / R04 | Use visual hierarchy: detail, ornament, density, emptiness and ordinary elements each need a stated role in the world/story/function. | C04–05,07–08,12,16,24; not minimalism. |
| AD-DR08 | DEFAULT | 03–04,12,16 / R06,R13 | Coordinate set, costume, material, color, props and supported graphics as one world while retaining department-specific execution authority. | C07–10,12–13,17–20. |
| AD-DR09 | CONDITIONAL | 11,13–14,19 / R03,R12 | If historical/real-world grounding conflicts with production condition or chosen stylization, preserve story purpose and research trace, state the deviation, and escalate any Canon conflict. | C01,03,15–16,21,24. |
| AD-DR10 | CONDITIONAL | 02–03,14–15 / R10,R13 | Choose form, color, material, surface and density as a contextual system for cohesion/differentiation; never apply deterministic visual dictionaries. | C05–08,14,16,24. |
| AD-DR11 | CONDITIONAL | 07–08,13,15,19–20 / R07 | When design burden is high, offer lawful simplification or alternatives that preserve required story/world function; hand final cost/schedule decision to Production. | C04,08,12,21,23. |
| AD-DR12 | CONDITIONAL | 09–10,12,19 / R08 | Build character/costume appearance from lawful identity, world, period, use and feasibility; hand performance impact to Character & Acting without inferring psychology. | C09–10,19; no performance/arc invention. |

Counts: Hard `3`; Default `5`; Conditional `4`; Optional `0`. Rule traceability `12 / 12`; unsupported rules `0`.
