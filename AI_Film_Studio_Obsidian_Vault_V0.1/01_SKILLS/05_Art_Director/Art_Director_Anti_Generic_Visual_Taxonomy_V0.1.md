# Art Director Anti-Generic Visual Taxonomy V0.1

None of these elements is prohibited. The failure is an unmotivated, unresearched, unintegrated trope replacing lawful world logic.

| Pattern | Failure signal | Draft control |
| --- | --- | --- |
| Generic cyberpunk neon | neon substitutes for technology/social/world fact | Require world function, material/source and hierarchy. |
| Generic medieval dirt | dirt substitutes for period research | Require period/use/maintenance trace. |
| Generic luxury marble/gold | luxury surface substitutes for status/world function | Require material/world/character function and differentiation. |
| Generic Japanese signage | language/culture used as décor | Require lawful place/culture fact and graphic evidence. |
| Generic Victorian clutter | accumulated objects replace history/function | Require each density layer to earn its place. |
| Generic sci-fi holograms | technology is added for spectacle | Require authorized technology/world function. |
| Random futuristic LEDs | surface novelty displaces visual concept | Tie to infrastructure, function and physical world. |
| Random grunge | decay is a mood overlay | Trace age/use/maintenance/world condition. |
| Arbitrary cultural symbols | symbol replaces research | Use source hierarchy/context; do not invent lore. |
| Random retro objects | period cue replaces period logic | Verify period, use and location context. |
| Detail density as quality | more details are assumed better | Apply hierarchy and story-service test. |
| Aesthetic trope replacing world logic | reference/style stack is the only rationale | Require `why this exists` in story/world/function terms. |

Trace: AD-DR04–10, especially R01–R05, R10–R11. This is a risk taxonomy, not a design dictionary.
