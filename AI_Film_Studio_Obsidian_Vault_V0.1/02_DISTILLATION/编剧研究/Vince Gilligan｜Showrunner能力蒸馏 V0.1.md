# Vince Gilligan｜Showrunner 能力蒸馏 V0.1

> 女娲 `huashu-nuwa` 方法论蒸馏。只提取可复用的角色因果判断；不含任何既有作品的情节、角色模板、犯罪元素、对白、视觉或人格模仿。
>
> “直接来源支持”可回溯至来源 ID；“综合推断”是 AI Film Studio 的操作化归纳，绝非 Gilligan 原话或万能公式。

## 蒸馏目标

构建 **Character Consequence Engine（人物选择—后果—升级发动机）**：从人物当前欲望、恐惧、约束与未结后果推导其下一选择；让后果更新局势和选择集，必要时形成可解释的升级；为 writers' room 提供可交接的 story-breaking 方式。

## 核心判断原则

### 人物状态优先【默认启发式】

**直接来源支持（VG-05）**：Gilligan 描述 room 反复追问人物现在所处状态、想要什么、害怕什么，并反对为了预设目的地扭曲人物。

**综合推断：** 先更新人物状态表，再提出下一步候选；“我们需要一个反转”不是充分的入场理由。

### 选择应留下持续后果【硬约束：关键剧情链】

**直接来源支持（VG-04、VG-05、VG-06）**：人物行动会产生余波；角色不应在下一单元自动回到原状；关键结果需要可追溯的人物责任。

**综合推断：** 对承担主要剧情重量的选择，至少记录它改变的关系、资源、信息、自我认知或可选项之一；否则该选择尚未形成可验证的人物驱动。

### 后果要成为下一选择的原因【硬约束：主链连续性】

**直接来源支持（VG-01、VG-04、VG-05）**：Gilligan 以故事能否 self-generate、持续后果和人物责任来说明连续叙事的推进。

**综合推断：** 主链应能复述为 `状态 → 选择/不作为 → 后果 → 更新状态与限制 → 下一选择`。箭头不能从人物视角解释时，标记为“因果链断裂”。

### 升级是条件结果，不是每拍任务【条件适用方法】

**直接来源支持（VG-05、VG-06）**：他要求人物真实与因果满足感，同时保留方向中的路径开放性。

**综合推断：** 仅当后果提高代价、收窄安全选项、损耗关系/资源或尖锐化价值冲突时，才称“升级”。允许兑现、消化、修复、观察或横向发展段落；反对只增加噪声或外部危险。

### 意外可用，但须经责任链检验【条件适用方法】

**直接来源支持（VG-05）**：Gilligan 承认可先有吸引人的意象或偶发起点，但在承诺其为核心转折前，要求找到主角对结果承担实质责任的解释。

**综合推断：** 随机事件可以是扰动/素材；它不能独占主剧情回报或抹去人物选择。用 `caused / enabled / worsened / responded` 检查人物如何进入责任链；确实无责任时，转而写人物如何应对它。

### Break story 是共同推演，不是点子堆积【可选工具 + 默认启发式】

**直接来源支持（VG-05、VG-06、VG-07）**：Gilligan 描述团队逐 beat、用卡片/软木板推演多条可能路径；break 的目标是令知情作者能够接手成稿，且既定想法可因更好证据被放弃。

**综合推断：** 卡片、白板或文档都只是载体；合格 beat 应让团队共同理解行动者、目的、前因、选择或功能、后果/完成状态，以及后续问题、下一决策条件或阶段性收束之一。

## 工作流程

### 输入

- 角色当前状态：至少一个欲望/目标，以及当前限制、承诺、风险、恐惧、未结后果或外部条件中的一项；
- 项目/季级方向与当前单元的边界；
- 可选的外部扰动、预设图像或候选结果。

### Story-breaking 循环

1. **状态盘点**：若缺少人物欲望/目标，或缺少会影响当前判断的限制、风险、外部条件等状态信息，先补信息；首集、新人物或新链条起点的未结后果可以为空。
2. **候选扩展**：提出多个下一选择、拒绝/隐瞒/求助等行动及外部扰动；每项写“为何此人此刻会这样做”。
3. **后果推演**：对候选至少推演一层直接后果和一层后果如何更新下一选择集。
4. **责任与 earned 筛选**：淘汰仅因作者需要、违背已建人物理解、或无法说明责任链的候选；重大转向需已有压力与状态证据。
5. **分类处理**：标记本 beat 是兑现后果、使状态可见、人物重新选择、条件升级，还是必要观察/恢复；不强制全数升级。
6. **可交接输出**：确认卡片/提纲写清行动者、当下目的、前因、选择或功能、后果/完成状态，以及后续问题、下一决策条件或阶段性收束之一；未验证的远期节点保持低承诺。

### 输出

- 人物状态表；
- `Choice → Consequence → Next Cause` 因果链；
- 升级/非升级段落标注及理由；
- writers' room 可交接的 beat 卡与淘汰候选理由；收束/兑现 beat 可不产生新问题，但须说明其完成、显露或恢复的功能。
- 因果链断裂与返工清单。

## 诊断问题

1. 此刻人物想要什么、害怕什么、背负什么未结后果？
2. 下一候选是人物能动选择，还是作者只想要一个反转？
3. 选择后具体改变了什么：关系、资源、信息、自我理解、风险或可选项？
4. 哪项后果使下一行动在此时成为必要/合理，而非天降危机？
5. 若观众感到意外，能否回溯到人物状态和责任链？
6. 这是否真是升级，还是仅提高声量/危险而未改变选择集？
7. 本段若非升级，它是否在兑现后果、显露状态、建立 POV、恢复代价或准备下一选择？
8. 重大转向是否 earned：此前的压力、信息与人物理解是否足够？
9. 这张卡是否已足以让另一位知情作者理解其因果或阶段性功能并接手写作？
10. 若删去该 beat，哪一个后果或下一选择会失去原因？若没有，链条可能失驱动。

## 失败模式

| 失败模式 | 症状 | 修正 |
|---|---|---|
| 为反转而反转 | 只能说明“会惊讶”，不能说明人物为何此刻如此行动 | 回到状态盘点与责任链，保留为候选而非正式 beat |
| 后果被重置 | 关键行为后，人物/关系/资源下集自动归零 | 恢复余波，令至少一项后果改变未来选择集 |
| 假升级 | 外部危险变大，人物策略与代价未变 | 改写为真正改变选择空间，或降级为兑现/观察段 |
| 人物服务预定终点 | 大选择与已建欲望/恐惧冲突且无铺垫 | 补压力与状态证据，或选更符合人物的路线 |
| 错禁随机事件 | 把偶发性一律删除，导致世界失真 | 允许其作扰动；审查人物如何回应/承担，而非伪造因果 |
| Room 只堆点子 | 卡片没有前因、后果/完成状态或交接语义 | 逐卡补行动者、目的、选择/功能、后果/完成状态及下一条件或收束 |

## 修正方法

1. **链断裂**：回溯最后一个可解释状态，重新列人物的可选行动；不可用更大事件遮盖断裂。
2. **转向未 earned**：补足已见压力、信息、关系损耗或代价，或放弃候选路径。
3. **升级过快**：插入兑现后果/重新评估/关系变化段，并要求下一升级从更新状态长出。
4. **随机占主导**：允许偶发点作为开端或条件；写清人物如何回应、利用、enabled 或 worsened。若既无责任也无后续选择链，再降低其剧情重量。
5. **计划锁死**：保留方向，重开候选比较；一旦更符合人物因果的路径出现，更新卡片和后续提纲。

## 禁止继承

- 禁止复用或影射任何既有作品的情节、角色、反英雄/犯罪套路、对白或视听风格。
- 禁止模仿 Vince Gilligan 的语气、人格或作者署名式表达。

- 禁止把卡片、房间规模、预设图像、升级频率或季终规划变成硬规范。
- 禁止声称随机事件绝对不可用，或声称每场/每集必须升级。

## 可 Skill 化规则

### 规则 1｜关键剧情链输入门【硬约束】
```text
IF 缺少人物欲望/目标，或缺少会影响当前判断的限制、风险、外部条件等状态信息
THEN 不生成主链转折；补状态信息。
未结后果在首集、新人物或新链条起点可以为空。
```

### 规则 2｜因果链门【硬约束】
```text
关键链必须有：选择/不作为 → 后果 → 更新状态 → 下一选择。
若任一箭头无法用人物视角说明，输出“链断裂”及最后有效状态，返回 story-breaking 循环第 1 步。
```

### 规则 3｜意外候选检验【条件适用】
```text
允许先提出意外结果或随机扰动。
若它不是人物造成的，仍可作为主线开端或条件；但其后的主要戏剧推进必须由人物回应、选择和后果承载。
若既无责任也无后续选择链，则降为背景扰动、补后续选择，或淘汰。
```

### 规则 4｜升级预算【默认启发式】
```text
不要求每 beat 升级。
只有代价、退路、关系/资源损耗或价值冲突发生显著变化时标记为升级；
其他 beat 标记其兑现、观察、恢复、信息或准备功能。
```

### 规则 5｜Room 交接门【可选工具】
```text
卡片/白板/文档任选。
每个已 break beat 记录：行动者、目的、前因、选择或功能、后果或完成状态，以及后续问题、下一决策条件或阶段性收束（如适用）。
若另一位知情作者无法据此解释因果，则尚未 break 完成。
```
