# SMOKE-SW-EXEC-01｜Original Assignment

- Project: `VALIDATION / SYNTHETIC / NON-CANON`
- Episode: `TEST-EP01`
- Scene: `SMOKE-SW-EXEC-01`
- Mode: `CREATE`
- Location: 办公室会议室。
- Prior state: 会议刚结束，只剩林妍和陈默。

## Scene Purpose

测试 Scene Writer 是否能将明确的人物目标、阻力与信息限制转换成一场短而可演的戏。

## Participants

**林妍**：项目组负责人。今晚必须确认明早演示由谁负责。她知道原定演示人临时不能到场，但不知道具体原因。她不愿在没有得到本人允许的情况下替对方解释。

**陈默**：项目成员。有能力接替演示，但今晚原本已经准备离开。他不喜欢临时被推责任，尤其讨厌别人用“大家都指望你”逼他答应。

## Required event and information

- 林妍必须提出让陈默代替明早演示。
- 原定演示人明早不能到场；原因未知，不得补写。
- Required post-scene state：陈默最终同意先接下演示，但要求林妍今晚把现有材料全部发给他。

## Locked constraints

- 不得创造原定演示人缺席的具体原因。
- 林妍不得谎称自己知道原因。
- 陈默不得一开始就欣然答应。
- 不得把两人写成敌对关系。
- 不得加入第三个角色。
- 不得修改为其他地点。

## Creative freedom

具体对白、停顿、动作、试探方式可以由 Scene Writer 决定。产出必须是短场景，以完成戏剧功能为准；不得扩展为完整剧情。
