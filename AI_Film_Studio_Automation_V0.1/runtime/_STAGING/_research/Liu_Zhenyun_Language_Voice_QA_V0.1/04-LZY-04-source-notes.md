## 可直接支持｜SOURCE-SUPPORTED

1. **人物想说但无人听，作者自述成为听者。** 刘震云以“人物想说一句话、所有人不听，作者成为听者”的方式讨论听与被听；这是可直接确认的事实性发言内容。
2. **作者自述听人物如何说。** 该发言直接支持“作者倾听人物”这一创作关系；“说话必须有人听”“人物不得只充当作者话筒”及其 QA 规则属于后续综合推断。
3. **表面不说话不等于没有内在活动。** 他转述读者对人物“表面不说话、内心思考不同”的发现；可作为 Silence / Spoken ≠ Inner 的有限来源基础。
4. **写出的文字与未写内容形成关系。** 他明确把“写和没写的结构”作为创作问题；可为言外信息与克制提供来源基础。

## 综合推断｜SYNTHESIZED INFERENCE

- 从“有人说 / 有人听 / 所有人不听 / 作者倾听”归纳出：交流需要检查实际 Receiver，接收失败会改变处境；这不是来源原列硬规则。
- 与 LZY-02 的“人物认知不等于作者认知、作者影子退后”交叉后，归纳出 `AUTHORIAL COLLABORATION` 风险：多个人物若以同一抽象语言共同完成作者结论，应核查互动真实性。
- 从表面沉默与内在活动分离、写与没写的关系归纳出：沉默可有功能，但不能由 QA 自动解释其全部心理。

## 项目综合｜AI FILM STUDIO SYNTHESIS

以下均不是刘震云原列术语或流程：

- `SPEAKER → RECEIVER → RELATIONSHIP → PURPOSE → SPEECH FORM`
- `INTENDED → SPOKEN → RECEIVED → RESPONSE`
- `Conversation State`
- `Self-Interpretation Gap`
- `QA / REWRITE / LEVEL 0–5 / Meaning Lock / Role Handoff`

## 不可外推

- 不得把“没有人听”变成每场必须发生的交流失败。
- 不得把沉默做成高级表达配额，或据此推断人物全部内心。
- 不得复制对谈中的作品情节、角色、比喻、幽默或刘震云个人表达。
- 不得把作者“倾听人物”直接等同于完整的 Runtime QA 协议。
- 不得把“写与没写”变成每句必须有潜台词或省略。

## 采用决定

`CORE FIRST-HAND SOURCE`。它补足候选三份材料中对 Receiver / Listening / Character Autonomy 的直接证据，但不单独证明完整 Social Communication Engine。
