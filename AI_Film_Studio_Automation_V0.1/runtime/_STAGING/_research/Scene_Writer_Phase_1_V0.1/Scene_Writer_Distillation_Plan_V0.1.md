# Scene Writer Distillation Plan V0.1

## 目标与范围

下一步只可从 `SW-S01 BBC Writersroom`、`SW-S02 Academy Nicholl`、`SW-S03 Writers Guild Foundation` 提取可复核的方法单元，优先覆盖 `SW-C01–C12`、`SW-C15`。这不是对作者风格、任何受版权保护剧本片段或既有作品人物的模仿。

`SW-C13` 与 `SW-C14` 暂不作为“来源已支持”的能力承诺：若需写入未来能力模型，必须分别以 `SYNTHESIZED INFERENCE` 或 `AI FILM STUDIO SYNTHESIS` 标明依据和验证边界。

## 逐源方法单元格式

每个单元必须包含：

1. 来源链接、访问日期、公开可用性与最小必要引述/释义。
2. `SOURCE-SUPPORTED` 方法陈述（可追溯、不可夸大）。
3. 映射的 SW-C 能力项与反例/失效条件。
4. 转化为项目中性检查问题，不继承个人文风、人物、情节或表达习惯。
5. 与 Showrunner、Shared QA、Director、Character & Acting、Art Director、Continuity 的权限边界。
6. 一个可合成验证样例，标记 `SYNTHETIC / NON-CANON`。

## 建议顺序（仅计划，未启动）

|阶段|来源|产物|闸门|
|---|---|---|---|
|D0|全体|来源版本、可用性与权利复核表|链接可访问；只使用公开正文。|
|D1|BBC Writersroom|可拍性/动作节拍/格式边界方法卡|不把格式要求误升格为导演指令。|
|D2|Academy Nicholl|视觉叙事、行动、冲突与描述边界方法卡|不把竞赛规则迁移为项目政策。|
|D3|Writers Guild Foundation|对白功能、潜台词、信息投递、角色声音语境方法卡|不复用示例剧本中的版权表达。|
|D4|交叉整合|Scene Writer 候选能力模型（仅候选）|逐项标明来源支持与系统合成。|
|D5|未来|针对 C13/C14 的独立研究计划|未完成前不宣布完整生产能力或创建 Skill。|

## 未来验证计划（不在本轮执行）

|测试|输入|通过条件|不得发生|
|---|---|---|---|
|SW-T01 内心独白转行动|含“他意识到/她感到”的合成段落|有触发、可见反应、选择/后果；含义仍受锁定。|把潜台词解释成旁白。|

## 明确不做

- 不生成 Scene Writer Production `SKILL.md`。
- 不写完整剧本或任何项目正片场景。
- 不绑定 Runtime / Executor，不调用模型作为本阶段验证。
- 不启动 Director、Character & Acting、Art Director 或 Continuity。
