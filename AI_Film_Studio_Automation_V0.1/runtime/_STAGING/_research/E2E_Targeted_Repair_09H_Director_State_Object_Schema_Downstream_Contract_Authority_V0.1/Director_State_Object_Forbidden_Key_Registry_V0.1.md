# Director State Object Forbidden Key Registry V0.1

## Established prohibition

The exact outer Director contract and role boundaries forbid nested state objects from being used to smuggle a duplicate outer control field or another role's decision. The following names are not lawful nested state-schema authority: `selected_mode`, `primary_state_or_outcome`, `flags`, `handoffs`, `required_outcome`, `unresolved_decisions`, `canon_assignment_locks`, `prohibited_changes`, `scene_packages`, and the eight Director prose-deliverable fields.

These are forbidden as duplicate transport/control data, not because a model once omitted them.

## Not frozen

No additional literal nested-key registry may be invented for Canon, Art Director design, Character & Acting method, or Showrunner outcomes until a positive per-field property list exists. Category-level boundaries remain mandatory, but they are not falsely represented as exact JSON-schema properties.
