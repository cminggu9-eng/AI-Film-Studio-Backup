# Director State Boundary Ownership Contract V0.1

| Boundary | Owner | Responsibility | Representation |
|---|---|---|---|
| Director semantic layer | Director within locked authority | state value only; no Canon, Acting, Art Design, or story decision | object or `ABSENT` |
| Provider-neutral contract | Integration contract | exact future schema validation; no semantic creation | object or `ABSENT` |
| DeepSeek strict function schema | Provider projection | enforce the approved schema as wire shape | currently legacy string workaround; future object only after schema approval |
| local validation | Integration | fail closed; preserve values; no coercion/inference | must follow future object schema |
| State Evidence / Ledger / Handoff | Integration transport | source-attributed, JSON-safe canonical carriage | object or `ABSENT` |
| display projection | Integration | lossless display only | no new semantic state |

No boundary may create a nested property merely to make strict schema construction convenient.
