# Director State Object Schema Authority Map V0.1

| Authority level | What it establishes | What it does not establish |
|---|---|---|
| Canonical Director Skill | lawful staging, spatial, visual, audience-information, rhythm intent; role boundaries | any five-field nested state schema |
| 09B structured submission | five fields are `object` or `ABSENT`; all state dimensions are model-owned | properties, required keys, value types, enums, forbidden nested keys |
| State Evidence / Ledger | six outer dimensions; no null; JSON-safe preservation; exact `ABSENT` sentinel | string-only transport or nested object shape |
| compiled fixture contract | fixture-derived Scene Writer state dimensions/enums and transitions | Director state-object mapping or stable nested names across fixtures |
| interface / acceptance contracts | source attribution, prior/current/proposed, knowledge/visual continuity, no inference | property-level encoding |
| historical outputs | observed payload variations | semantic authority — expressly excluded |

## Gate conclusion

Every one of the five requested exact schemas lacks a source that can lawfully close its keys and types. This is a **STATE SCHEMA AUTHORITY GAP**, not an implementation defect. The authority hierarchy and anti-reverse-spec rule were applied; no model output was promoted to contract.
