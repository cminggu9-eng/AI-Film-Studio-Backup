# Scene Writer Scene State Model V0.1

## Formal Working Model

```text
BEFORE STATE
  → CHARACTER INTENTION / APPROVED OBJECTIVE
  → ACTION
  → RESISTANCE
  → RESPONSE / ESCALATION / DISCOVERY / CHOICE
  → MEANINGFUL STATE CHANGE
  → JUSTIFIED EXIT CONDITION
```

This is a diagnostic construction sequence, not a compulsory beat template. It does not establish a closed taxonomy of turns or require every scene to contain every visible step.

|Element|Required decision|Permitted expression|Boundary|
|---|---|---|---|
|Before State|What current pressure, relation, information, access, obligation, or condition comes into the scene?|Narrow prior-state context and first effective dramatic information.|Cannot replace project premise, Canon, episode objective, or arc destination.|
|Character Intention / Approved Objective|What does each relevant participant presently attempt, protect, avoid, obtain, hide, test, exchange, or decide?|Scene-facing intention drawn from Assignment/Canon or safely inferred from sufficient context.|Do not invent a macro goal or locked character desire.|
|Action|What encounterable event or active dialogue makes the attempt playable?|Visible/hearable action, dialogue action, choice, reaction, silence, relevant object/sound/spatial change, or authorised interior form.|No camera plan or acting blueprint.|
|Resistance|What blocks straightforward achievement?|Other aim, information, timing, environment, consequence, relationship pressure, or condition.|Not automatically an argument, fight, or new conflict.|
|Response / Escalation / Discovery / Choice|What occurs in response to pressure?|A response, increased pressure, discovery, choice, or relation/information movement as relevant.|No required reveal or fixed turn type.|
|Meaningful State Change|What is now different in a way that matters to the scene or later dramatic pressure?|Change in action direction, relation/access, information/working inference, pressure/risk, commitment, obligation, or other approved condition.|May be modest, quiet, partial, or unresolved; not necessarily a reversal.|
|Justified Exit Condition|What must remain for function, changed pressure, or aftermath to land?|End at the point where required function is complete, including lingering/silence/reaction if they still work.|Final cut rhythm remains Director/Editor territory.|

## Scene Turn Benefit Test

A claimed turn is meaningful only when it changes at least one relevant dimension:

- current objective or action direction;
- relationship, access, commitment, obligation, or power relation;
- information state or audience’s usable working inference;
- pressure, risk, consequence, or next-scene condition; or
- a Showrunner-required dramatic effect.

An event without any such effect is not promoted to a “turn” merely for structure. Conversely, a quiet decision can be a valid turn when it changes one of these dimensions.

## Entry and Exit Tests

**Entry:** choose the earliest point at which the scene’s relevant current pressure and causal conditions can be legible. Arrival, routine, silence, setup, or preamble stay if they perform that work.

**Exit:** leave when the required function has reached its justified completion point. Aftermath, silence, reaction, unresolved pressure, or delayed departure stay if they remain the dramatic event or establish the next state.
