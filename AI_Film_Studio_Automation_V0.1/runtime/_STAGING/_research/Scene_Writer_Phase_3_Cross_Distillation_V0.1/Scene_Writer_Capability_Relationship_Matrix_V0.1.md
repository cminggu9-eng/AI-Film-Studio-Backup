# Scene Writer Capability Relationship Matrix V0.1

> **Scope:** Cross-distillation only. This matrix relates approved source methods; it does not create a Capability Model, production Skill, Runtime, Executor, or source-independent rule.
>
> **Classification key:** `CONSENSUS` = independent methods support the same bounded principle; `COMPLEMENTARY` = methods serve different parts of a workflow; `OVERLAP` = retain once at rule layer; `CONDITIONAL TENSION` = both remain valid under different conditions; `TRUE CONFLICT` = cannot both apply in the same conditions.

## Interpretation Limit

The five conditional tensions are not unresolved conflicts: each has a bounded condition, a non-mechanical failure mode, and a handoff/stop condition. Formal conflict arbitration is therefore recorded as **not required**, not skipped.
