# Scene Writer Unshootable Language Evidence Notes V0.1

> This is evidence collection only. It is **not** the final Unshootable Language Taxonomy and creates no new Studio rule.

## Evidence-backed patterns

|ID|Question|BBC Writersroom|Academy Nicholl|Writers Guild Foundation|Evidence-bound note|
|---|---|---|---|---|---|
|UL-E01|Can screenplay action directly report a private thought or backstory?|Direct support: scene action is limited to on-screen happenings, not superfluous novelistic thought/backstory.|Direct support in adaptation context: prose inner thought/feeling must be made legible by screenplay/performance.|No direct visual-description rule read.|A private conclusion is weak screen action **when it has no screen carrier**. The sources do not create a ban on approved voice-over or narration devices.|
|UL-E02|What must be externalized?|Screen action requires an on-screen event.|Film is visual; viewer must see action. The guide contrasts prose interiority with writer/actor showing feeling.|Dialogue, subtext and contextual speech give interaction routes, not a universal externalization doctrine.|Source support exists for an observable/performance carrier; no source prescribes one fixed gesture, prop, or reaction.|
|UL-E03|Can behavior, dialogue, objects, or reactions carry information?|Screen action and action beats support visible event structure; no specific prop method read.|Actual guide asks what is learned from actions versus speech; visual story need not depend on much dialogue.|Dialogue friction, subtext, and clue-scaled exposition offer interaction-level carriers.|Use the carrier that preserves the current dramatic relation. “Behavior” is not a substitute for meaning; a prop/reaction is not automatically valid without scene relevance.|
|UL-E04|When are narration/description legitimate?|No universal narration rule read; BBC only constrains scene-action content.|No narration doctrine read; acting/writing comparison is adaptation-specific.|WGF warns by implication against total explanation, but says “show” is not “show everything.”|Current source set does not support a universal narration policy. Project-approved narration remains outside this note’s authority.|
|UL-E05|How to avoid mechanical Tell → Show?|BBC’s paragraph length is a rule of thumb, not complete drama method.|The source says visual does not mean no dialogue.|WGF explicitly supports clues, indirect subtext, and situational dialogue; it does not say every emotion must be hidden.|Do not mechanically remove exposition, dialogue, or direct speech. Diagnose whether the audience has a playable/observable carrier and whether the current scene purpose remains intact.|

## Evidence traces

- **BBC:** E-BBC-01, viewer PDF p.2 / printed p.1, “Scene action”; a significant action beat is a rule of thumb in the same section.
- **Academy:** E-AN-01, viewer PDF p.3, “Structuring a Screenplay”; p.4, “Developing a Screenplay from a Book”; p.5–6 activity masters on visible action and information learned from action versus dialogue.
- **WGF Dialogue:** E-WGF-01, article heading and closing questions on conflicting objectives.
- **WGF Subtext:** E-WGF-02, closing exercise on indirect carriers.
- **WGF Backstory/Exposition:** E-WGF-04, clue/nugget/hint discussion and exercise; the body explicitly rejects “show everything.”

## Not supported by the current source set

- A final taxonomy with universal pass/fail labels.
- A mandatory object/prop/reaction template.
- A universal ban or permission rule for narration, voice-over, or literary description.
- Any AI-generation, prompt-engineering, or character-consistency rule.
- A decision on whether a specific project passage is shootable; no project passage was supplied or tested.
