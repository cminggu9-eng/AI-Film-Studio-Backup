# Shonda Rhimes｜Series Engine 证据工作区 V0.1

本目录仅存放本轮未审核的证据与审计材料；不是 Obsidian 正式内容，也不是可发布的最终蒸馏。

## 边界

- 核心结论必须由 Shonda Rhimes 本人的可公开核验陈述支撑。
- 课程目录或宣传页仅可证明公开描述，不可代替课程内容。
- 二手资料只能辅助定位或交叉核验，不能独自承载核心方法主张。
- 最终稿以 `SOURCE-SUPPORTED` / `SYNTHESIZED INFERENCE` 区分证据与归纳。
- 排除具体作品剧情、人物模板、题材刺激物、对白／视觉风格与模仿人格。

## 预期文件

- `01-primary-interviews.md`：一手访谈与公开文字
- `02-series-and-room.md`：showrunning、room、episode／season 机制材料
- `04-evidence-audit.md`：最终核心来源账本、来源—主张映射与边界审计
