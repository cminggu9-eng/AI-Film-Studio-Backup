# Director Structured Contract Single Source of Truth V0.1

The provider-neutral Director Full Structured Submission contract now exposes one deterministic manifest. Its field set and required set derive from `director_submission_schema()`.

The same manifest governs:

1. DeepSeek compatibility projection and final function parameters.
2. The derived structured Director system-prompt instruction.
3. The local exact-field validator manifest.
4. The eight-field deterministic display projection.

The structured Director prompt no longer serializes the generic role transport schema. It receives a derived field manifest, canonical mode/state domains, state serialization rule, exact-field prohibition, and runtime carry-forward rule.
