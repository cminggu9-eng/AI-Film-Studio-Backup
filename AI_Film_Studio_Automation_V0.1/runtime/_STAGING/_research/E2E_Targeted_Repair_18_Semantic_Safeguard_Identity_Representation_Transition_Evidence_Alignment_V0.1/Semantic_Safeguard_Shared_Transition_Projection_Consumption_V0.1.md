# Semantic Safeguard Shared Transition Projection Consumption

The harness no longer selects an occurrence scene by searching `authorized_transitions`. It builds one `SHARED_TRANSITION_AUTHORITY_PROJECTION`, classifies existing scene-local state evidence, and passes that machine classification to the Safeguard assertion.

The Safeguard blocks unauthorized, not-occurred, or unobserved required changes with distinct Integration codes. It does not create a second transition law.
