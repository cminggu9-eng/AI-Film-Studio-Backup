# Continuity Failure Classification Contract V0.1

| Failure | Classification |
|---|---|
| Non-object or inexact top-level transport; missing machine field | TRANSPORT / PARSER CONTRACT FAILURE |
| Invalid/translated/aliased canonical outcome | ROLE SEMANTIC FAILURE |
| Missing/wrong/null six-dimension State Evidence | STATE TRANSPORT FAILURE |
| Non-ABSENT forbidden authority transport | HANDOFF CONTRACT FAILURE |
| Unauthorized strict Continuity path | STRICT TRANSPORT AUTHORIZATION FAILURE |
| Validator rejects valid outcome/evidence because of non-authoritative prose heuristic | TRANSPORT / PARSER CONTRACT FAILURE |

Classification never rewrites or repairs the role response.
