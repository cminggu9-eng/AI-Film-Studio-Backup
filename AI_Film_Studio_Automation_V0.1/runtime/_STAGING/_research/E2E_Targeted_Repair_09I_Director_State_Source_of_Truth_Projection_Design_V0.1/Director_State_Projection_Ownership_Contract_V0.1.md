# Director State Projection Ownership Contract V0.1

- Upstream role owns original state, knowledge, transition, and lock facts.
- Integration owns deterministic source selection, projection, validation, package construction, and fail-closed behavior.
- Director owns only lawful directorial intent/impact content within an already supplied contract; it does not rename, summarize, merge, or redefine upstream facts.
- State Evidence / Ledger / Handoff own source-attributed object carriage; display is lossless only.

No Integration projection may create a new semantic record merely because the target Provider requires a closed schema.
