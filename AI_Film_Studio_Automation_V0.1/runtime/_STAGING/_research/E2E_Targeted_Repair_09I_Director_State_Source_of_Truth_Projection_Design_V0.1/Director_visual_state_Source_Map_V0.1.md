# Director visual_state Source Map V0.1

| Map element | Source-backed finding |
|---|---|
| Primary authority source | compiled `state_dimensions` and validated Scene Writer state snapshots |
| Secondary carried source | lawful spatial / production constraints and source attribution |
| Projection owner | Integration |
| Projected keys | dynamic compiled state dimensions are exact per binding; selection of which dimensions/scenes are the Director visual projection is **OPEN** |
| Requiredness / type | compiled state object is closed per binding; Director visual projection scope is OPEN |
| Token source | `state_dimensions[].allowed_tokens` from compiled run contract |
| Forbidden-key source | Director/Art Director/Character & Acting/Showrunner authority boundaries |
| ABSENT rule | only if approved source lacks visual/physical state; not when selection fails |
| Director writable dimensions | none for carried state; Director cannot add Art Director design or acting-method fields |
| Failure route | `VISUAL_STATE_PROJECTION AUTHORITY GAP` |

`AUTHORITY OPEN`: all three fixtures prove generic compiled dimension derivation, but none establishes a stable rule for which scene/dimensions form this Director field without copying an entire upstream artifact.
