# Director knowledge_timing Source Map V0.1

| Map element | Source-backed finding |
|---|---|
| Primary authority source | compiled `knowledge_events` and validated Scene Writer knowledge evidence |
| Secondary carried source | accepted reveal timing in the source scene/ledger record |
| Projection owner | Integration |
| Projected keys | **OPEN**: fixture contract requires a list and documents holder/timing categories, but defines no closed machine schema for an event or its Director projection |
| Requiredness / type | outer object/`ABSENT` known; nested event/holder/timing requiredness OPEN |
| Token source | binding-specific event data; no closed Director property mapping |
| Forbidden-key source | Director must not leak, retime, or invent character/audience knowledge |
| ABSENT rule | only with source-declared absence; unknown is not `ABSENT` |
| Director writable dimensions | none for knowledge facts or reveal timing |
| Failure route | `KNOWLEDGE_STATE_PROJECTION AUTHORITY GAP` |

`AUTHORITY OPEN`: existing records establish that knowledge and timing are carried, but not a generic strict source record with property closure suitable for Provider projection.
