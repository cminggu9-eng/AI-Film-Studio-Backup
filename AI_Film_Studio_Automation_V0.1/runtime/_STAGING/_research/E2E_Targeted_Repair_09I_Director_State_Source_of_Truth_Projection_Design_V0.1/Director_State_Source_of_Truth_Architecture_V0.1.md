# Director State Source-of-Truth Architecture V0.1

## Approved architecture

`AUTHORIZED SOURCE RECORD -> DETERMINISTIC INTEGRATION PROJECTION -> DIRECTOR STATE OBJECT -> DIRECTOR VALIDATION -> DOWNSTREAM OBJECT CARRIAGE`

The Director never invents an upstream-state shape. Integration owns projection mechanics; upstream roles retain original facts; Director owns only lawful directorial meaning inside locks. State Evidence / Ledger / Handoff carry JSON objects (or exact `ABSENT`).

## Closure rule

A field is `AUTHORITY CLOSED` only when its source record, selection/winner rule, projected properties, requiredness, types, token domains, forbidden keys, absence rule, and Director mutation boundary are all already authorized. A deterministic transform cannot close an absent semantic decision.

## 09I result

The architecture is approved, but no field reaches closure because the existing contracts do not define the required source selection and/or nested source-record schemas. The later implementation must not replace those decisions with LLM interpretation.
