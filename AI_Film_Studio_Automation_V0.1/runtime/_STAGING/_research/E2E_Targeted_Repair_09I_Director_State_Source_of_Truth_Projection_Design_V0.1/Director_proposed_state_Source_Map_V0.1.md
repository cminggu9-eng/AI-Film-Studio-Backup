# Director proposed_state Source Map V0.1

| Map element | Source-backed finding |
|---|---|
| Primary authority source | shared transition authority projection and compiled authorized transitions |
| Secondary carried source | current state, locks, prohibitions, allowed scene window |
| Projection owner | Integration for authority projection; Director only for a lawful impact choice once contract exists |
| Projected keys | shared transition projection has `transition_id`, `state_dimension`, `from_state`, `to_state`, authority/window/constraint/evidence fields; no approved Director delta selection record |
| Requiredness / type | source projection is structured, but its mapping to Director proposed state is **OPEN** |
| Token source | compiled `authorized_transitions` and `state_dimensions[].allowed_tokens` |
| Forbidden-key source | Showrunner / Scene Writer authority locks and Director boundaries |
| ABSENT rule | lawful only when no transition is applicable under the approved state source, not when a choice is unresolved |
| Director writable dimensions | no upstream transition fact; a future contract must state whether Director may select an already authorized transition |
| Failure route | unspecified delta/selection authority -> `CONTRACT DESIGN REQUIRED` |

`AUTHORITY OPEN`: the transition authority record proves what is allowed, not the exact Director-owned proposed-impact object or the decision rule that selects it.
