## SW-C13 Production Compression Evidence Limits

|Candidate conversion|Evidence status|Reason|
|---|---|---|
|Multiple locations → fewer/multi-use location|Partial direct support|Film Independent states a location manager may find multiple locations in one.|
|Unnecessary speaking roles → character consolidation|Not supported|No eligible Phase 2B source method.|
|Expensive transport/location → cheaper dramatic equivalent|Partial support|Location cost must be weighed with travel/lodging; no general substitution recipe.|
|Crowd scale → smaller equivalent configuration|Not supported|Extras are a burden signal, not evidence for reducing scale.|
|Remove an unnecessary element if no dramatic function|Not supported as a compression rule|Scene function is supported by Scriptnotes; Film Independent does not join it to a removal doctrine in this phase.|
