## 可直接支持的方法论

### 1. Meaning Before Wording

**SOURCE-SUPPORTED｜强支持**

- L46–L48：叶圣陶区分“用词适合、造语通顺”与文字是否忠实承载写作者实际思想情感。形式上通顺，并不足以证明表达完成了本意。短摘录：**“所写与所想一致”**。
- L53–L55：所谓“精密”包括在写出时不漏失原本意思情感，并明确指出“唯一适当的字”是过甚说法。这支持先确认要保留的意思，再在多个可通的表达中判断哪一个更准确。
- L72–L73：词语适合与否，要同时对照所指事物及词语意蕴；不准确既可能源于对对象体认不足，也可能源于不清楚词义和用法。
- L76：叶圣陶明确限定，“通 / 不通”只是就文字而言，并假定内在思想情感没有毛病。这直接支持把“语言通顺检查”与“意思是否正确、充分”分层。
- L82–L85：写作包含两层功夫：先认真想，再用相当的语言文字表达；修改不仅处理字面，也可能暴露并修正思考本身的问题。

**SYNTHESIZED INFERENCE｜可用于本项目，但不是原文公式**

可转译为 QA 顺序：

1. 先复原 Intended Meaning；
2. 再描述 Current Expression 实际让人理解成什么；
3. 比较两者是否错位、遗漏或过度扩张；
4. 只有存在错位时才提出 Repair；
5. 修订后回查意思是否仍被保留。

“Intended Meaning → Current Expression → Mismatch → Repair”是 AI Film Studio 的操作化归纳，不是叶圣陶原文中的固定流程。

### 2. Expression Accuracy

**SOURCE-SUPPORTED｜强支持**

- L37–L38：表达应完整、可理解；不硬用不了解的词，不强凑不适当的词，并留意连词、助词与长段表达的顺序。
- L47：文章即使“用词适合，造语通顺”，仍可能因为内容不是写作者真正所想而“不好”。这直接支持区分“语法正确”与“意思准确”。
- L67–L75：叶圣陶把文字“通”拆为词语适合与篇章调顺；介词、连词、助词如果失职，可能违反本来要表达的意思，或造成关系不清。
- L72–L73：词语选择须符合事实对象和词语意蕴；例子说明强度、性质或语境不相称，会使字面看似成立但表达失准。
- L84：对“上海的住旅馆”一例的分析，明确追查了句法表面所建立的错误归属关系，并通过极小修改恢复实际施事关系。

**SYNTHESIZED INFERENCE｜适合提炼的 QA 维度**

- 指代与施事是否稳定；
- 主语、对象、所属关系是否被句法写错；
- 因果连接词是否真正表达所声称的因果；
- 词语的范围、程度、性质是否超出事实或本意；
- 抽象词是否是已经理解的概念，而非借来填充的词；
- 句子是否虽无语病，却把说话者并未确认的内容写成事实。

这些维度由多个段落综合生成；“指代、范围、程度、过度断言”等现代 QA 标签并非来源原有术语。

### 3. Clarity / 顺当

**SOURCE-SUPPORTED｜强支持**

- L38：阅读或听取他人表达时，不应只满足于大概懂意思，还应观察用词、表达方式，以及长段语言如何顺次展开。
- L67–L68：文章的可通行性取决于词语适合与篇章组织调顺。短摘录：**“篇章组织得调顺”**。
- L74–L75：表示关系的介词、连词、助词会影响意思是否完整、关系是否成立；仅知道文法规则而未形成实际语言判断，容易得到“不过不错”的呆板结果。
- L75：成文后诵读几遍，可以发现不调顺之处，并帮助定位修改方向。
- L85：清明的思想对应有条理、组织完密的语言；朦胧表达可能反映思考尚未真正成形。

**SYNTHESIZED INFERENCE｜可操作检查**

- 主干是否能被识别；
- 信息顺序是否服务理解；
- 修饰语作用范围是否明确；
- 句间逻辑是否真实存在，而非由连接词假装成立；
- 重复、名词化和抽象链是否遮住了行动、主体或关系。

来源支持“关系、顺序、组织、调顺”的总原则，但没有直接提出“名词化密度”或“抽象链”这两个现代诊断名词。

### 4. Over-Editing Protection

**SOURCE-SUPPORTED｜中等支持**

- L55：叶圣陶明确说把某个字称为“唯一适当”未免言过其实，同时承认多个都能说通的字之间仍可比较精密程度。这反对把修订伪装成唯一正确答案。
- L75：他批评只逐处套用文法、结果“不过不错”的呆板做法，提示规则合规不等于表达质量，也不能支持机械改写。
- L84：修改的正当目标是把错的改对，或把较差的改得更正确、更完美；其理由来自思想或表达的具体问题，而不是“只要能改就应该改”。短摘录：**“修改思想”**。

**SYNTHESIZED INFERENCE｜项目护栏**

- 若原句已准确、清楚，并符合当前 Register，应允许 **NO CHANGE**。
- 不应为追求短、口语化、文学性或单一审美而改动已经工作的文本。
- 有多个等价可行方案时，应说明差异，不把偏好包装成唯一答案。

“NO CHANGE”不是叶圣陶原文标签；它是根据“修改必须有对象、有理由”和“唯一适当之字是过甚说法”形成的 AI Film Studio 护栏。

### 5. 修改理由与可解释修订

**SOURCE-SUPPORTED｜强支持**

- L73：叶圣陶不只指出词语不当，还追查两类病因：对事物体认不真切，或对词语意蕴理解不足；并建议以词典和同类表达比照来判定。
- L75：对关系词和语句不顺的检查要求了解“所以然”，并以诵读辅助发现问题，而非只报结论。
- L84：修改示例依次展示原句造成的错误关系、错误为何发生、怎样用最小改动恢复正确关系。这是“问题—理由—修法—意义复核”的直接原型。
- L53–L61：比较不同词语时，叶圣陶逐一说明它们建立的关系和表达深度有何差异，而不是只给一个替换答案。

**SYNTHESIZED INFERENCE｜项目工作格式**

可转译为：

`原文 → 问题定位 → 理由 → 一个或多个修订候选 → 含义保真检查`

该五段格式是现代 QA 工作流，不是来源中的明文模板；来源直接支持的是“说明所以然、比较候选、以意思和事实检验修订”。

## 不可外推边界

1. **不能外推为风格模仿。** 来源讨论写作与修改判断，不授权复制叶圣陶的年代词汇、句式、文学气质或人格声音。
2. **不能外推为单一现代汉语规范。** 文中包含特定时代的教育与“今话文”语境，不能直接成为当代 Project Brief、Trailer Copy、Dialogue、UI 文案等全部 Register 的统一范式。
3. **不能外推为“所有文本越口语越好”。** L37 的口语—书写联系和 L75 的诵读检查，支持用口头语言发现不顺，但不证明正式书面文本必须改成对白口吻。
4. **不能外推为“所有句子都必须朗读”。** 来源把诵读作为发现不调顺之处的方法，没有把它规定为每次、每句、每种 Register 的强制工序。
5. **不能外推为“越短越清楚”。** 来源要求适合、调顺、组织完密，并没有把删字量或句长当成清晰度指标。
6. **不能把“诚实”直接等同于事实核查。** 文中“诚实”主要涉及思想情感与表达一致、观察周至；现代生产文本的事实准确性仍需另行核验。
7. **不能据此建立唯一正确改法。** 来源自己限定“唯一适当的字”是过甚说法，故更适合支持候选比较与理由说明。
8. **不能用文学例子强制所有生产文本追求文学“传神”。** 项目可继承意义保真与词义精确，不继承文学评价目标。
9. **不能把思想与语言的紧密关系机械化为“表达不清必然说明创作者没想清楚”。** 来源提供了这种诊断方向，但具体项目还可能受上下文缺失、术语约定、协作交接或 Register 限制影响。

## 核验结论

YST-01 对本轮最核心的 `Meaning Before Wording`、`Expression Accuracy`、`Clarity / 顺当` 与“修订必须说明理由”提供了直接且较强的一手文本支持；对 `Over-Editing Protection` 提供的是中等强度支持，`NO CHANGE` 需要明确标注为项目归纳。该来源不直接覆盖现代 AI 痕迹、多 Register 切换、Trailer Copy、Dialogue 或 Project Brief 的专用规则，相关内容必须标为 `AI FILM STUDIO SYNTHESIS`，不能伪装成叶圣陶原话或原始方法。
