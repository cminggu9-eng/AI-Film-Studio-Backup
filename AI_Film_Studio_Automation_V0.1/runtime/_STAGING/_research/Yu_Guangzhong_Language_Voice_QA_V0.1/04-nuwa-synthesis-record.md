# huashu-nuwa｜余光中主题化能力蒸馏记录

## 蒸馏类型

`主题化单人能力方法论蒸馏`。目标不是生成余光中人物 Skill，而是从公开一手材料提取 `Translation-Like Chinese Diagnosis` 的可执行判断。

## 证据输入

- 核心公开包：YGZ-01、YGZ-03、YGZ-04、YGZ-05（含同场本人论文附件）、YGZ-06。
- 受限入口：YGZ-02，只保留元数据，不进入方法主张。
- 项目约束：Language & Voice QA Charter、专属任务书、叶圣陶/汪曾祺/老舍正式边界。

## 女娲抽取链

### 1. Source Pattern

跨来源可重复观察到：动作被抽象名词和泛化动词拆散；外围介词、连接、代词和长修饰可能遮蔽主句；目标语不必复制源语表面结构；同一种外来影响既可能成功，也可能造成负担；源语理解无误仍可能需要重审中文组织。

### 2. Mechanism

`Core Clause / Participants / Action / Logical Relation` 被外围结构包装后，读者需要延迟识别主干、暂存更多修饰、反推责任或穿过抽象层才能理解。问题不在结构的外来来源，而在它是否为当前中文任务提供必要功能。

### 3. Decision Logic

`Context & Register → Meaning Lock → Core Clause Recovery → Structure Function Check → Actual Burden → Alternative Comparison → Decision`

仅当替代表达保持意义且降低真实负担时才建议修改；否则 `KEEP / NO CHANGE`。

### 4. Modern Translation

余光中材料提供历史性症状与翻译方法证据；下列内容必须归 `AI FILM STUDIO SYNTHESIS`：2026 当前用法、专业混合语言豁免、Anti-Purism、LEVEL 0–5、QA/Rewrite 权限、Meaning Lock、Handoff、CONTEMPORARY USAGE UNKNOWN、Long/Short 假阳性保护。

### 5. Failure Shield

- 不把“西化”变成错误标签。
- 不建立“进行/通过/实现/关于/被/的”黑名单。
- 不以更短、更古、更文言或更像余光中为目标。
- 不覆盖前三位能力；只记录 Overlap Candidate。
- 不把文学翻译的短句、少代词、诗歌文体偏好推广到所有 Register。

## 执行结论
