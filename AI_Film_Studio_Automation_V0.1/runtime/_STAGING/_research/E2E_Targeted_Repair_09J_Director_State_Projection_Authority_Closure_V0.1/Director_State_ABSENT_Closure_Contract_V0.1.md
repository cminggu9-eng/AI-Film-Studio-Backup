# Director State ABSENT Closure Contract V0.1

Exact `ABSENT` is permitted only when the authoritative projection rules determine that the field has no lawful projectable content.

- `relevant_prior_state`: only a source contract's explicit whole-scope absence.
- `current_state`: not a default; missing required current source fails.
- `proposed_state`: current contracts contain no Director-writable dimension, so exact `ABSENT`.
- `knowledge_timing`: no closed machine projectable record, so exact `ABSENT`.
- `visual_state`: no explicit classification metadata, so exact `ABSENT`.

Conflict, missing required source, compiler error, projection error, unknown value, null, and empty object are never equivalent to `ABSENT`.
