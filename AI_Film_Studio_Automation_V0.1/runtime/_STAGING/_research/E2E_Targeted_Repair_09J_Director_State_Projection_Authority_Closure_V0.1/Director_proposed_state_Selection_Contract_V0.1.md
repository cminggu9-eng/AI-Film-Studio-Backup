# Director proposed_state Selection Contract V0.1

Director owns no generic story-state mutation authority. A proposed dimension may exist only if a frozen contract explicitly marks it Director-writable, supplies an exact domain, preserves Showrunner/Scene Writer/other-role authority, and passes all locks and prohibitions.

The currently approved contracts contain no Director-writable state dimension. Therefore this field is closed as the exact typed sentinel schema:

```json
{"type":"string","enum":["ABSENT"]}
```

This is a valid authority result, not omitted data. Director prose, visual intent, or an allowed transition registry cannot manufacture a delta.
