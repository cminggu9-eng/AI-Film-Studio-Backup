# Craig Mazin｜Showrunner 能力蒸馏 V0.1

> 本文件是女娲 `huashu-nuwa` 方法在本任务范围内生成的首轮能力方法论蒸馏稿。它提取可复用的判断与工作流程，**不**提供人物介绍、文风模仿、作品复述、角色/对白/视觉风格复用。
>
> 证据规则：标为“**直接来源支持**”的内容可回溯到本文件的来源编号；标为“**综合推断**”的内容是将多份一手证据转成 AI Film Studio 可执行流程的归纳，不应被误写为 Craig Mazin 的逐字理论或放之四海皆准的规则。

## 蒸馏目标

将下列经过一手公开材料交叉验证的创作判断，转为 AI Film Studio Showrunner 可使用的开发、拆集、审稿与返工工具：

1. 用可争论的 central dramatic argument（中心戏剧论断）连接外部 premise、人物变化与结局。
2. 用人物的旧信念/盲点、目标、选择和后果生成因果剧情，而不是把人物塞入节拍表。
3. 诊断机械式结构、被动人物、重复冲突、只靠解释的变化，以及“结局只是停止”的问题。
4. 把电影级人物—主题关系谨慎扩展到有限季电视的“总论断 + 单集子论断”层级。

适用范围：有明确终点、以人物变化和因果叙事为主的电影、有限季剧集或季弧。它是强力诊断镜头，不是所有类型、群像或开放式连续剧的唯一正确形式。

## 核心判断原则

下列 `M1`—`M6` 是本次蒸馏为便于追踪而分配的**方法主张编号**；它们不是 Craig Mazin 已命名的术语。每项后的 `SN-*` / `PBS-*` 是其直接证据来源编号。

### 1. 主题应是可被反驳的论断，而不是题材标签

**直接来源支持（M1；SN-403、SN-483、SN-610）**：Mazin 将 theme/central dramatic argument 描述为可争论的判断；抽象名词本身不足以告诉创作者故事要检验什么。外部 premise（发生什么）与内在问题（真正关于什么）需相互承载。

**综合推断：** 在开发文档中并列写两句话：

- 外部 premise：什么条件或事件启动可拍的叙事？
- 中心戏剧论断：故事要通过人物行动检验的、可被不同立场反驳的判断是什么？

若两句话不能互相施压，先修两者的连接，不要先补节拍。

### 2. 结构是人物与论断关系的结果，不是先验页码指令

**直接来源支持（M2；SN-403、SN-502、SN-522）**：Mazin 明确反对从对完成品的结构分析倒灌到创作；其核心表述是结构来自人物与中心戏剧论断的关系。自然顺序或大纲可以提供材料，但不能替代人物变化。

**综合推断：** 节拍表只保留为审计层。任何“缺少中点/低点”的诊断，先改写为：人物的哪一项旧信念、目标、关系或策略尚未被迫改变？

### 3. 人物起点需要一个能维持的旧逻辑

**直接来源支持（M3；SN-403、SN-372、SN-522）**：人物通常从主题反面或尚未认识其真相的状态开始；恐惧、盲点或“可接受的不完美”让这个状态暂时能够持续。盲点不只是标签：要说明人物为何尚未看见、什么反馈才可能使其看见。

**综合推断：** 为每名核心人物写“起点状态卡”：旧信念/盲点、维护它的恐惧、当前外部目标、从该策略得到的短期安全，以及它造成的代价。

### 4. 情节的单位是针对人物的压力、选择与状态变化

**直接来源支持（M4；SN-307、SN-403、SN-060、SN-655、SN-665）**：人物与 plot 应共同设计；plot 要反复检验人物的核心问题。事件需要因果关联，连续冲突应改变人物状态；场景要能改变人物、呈现其欲望/需要或让其失败，并涉及选择及后果。

**综合推断：** 每个关键场或序列采用状态账本：

`前状态（信念/目标/关系/策略） → 针对性压力或信息 → 人物可选项 → 实际选择 → 后果 → 后状态`

若场后状态与场前状态等价，该场可能只是填充、重复升级或对话解释。

### 5. 转变必须在仍可退回旧路时用行动证明

**直接来源支持（M5；SN-403、SN-647、SN-665）**：人物不能只理解新方向；终局要出现不同于开端的决定，并以行动证明变化。Mazin 同时强调，有意义的选择在作出时应让替代路径仍显得可行。

**综合推断（并保留证据张力）：** 把终局设计为“仍有旧路可选的压力测试”，让人物选择新路并承担真实后果。这里不把“选择必须不可逆”当作硬规则：更准确的工作解释是“决定前有真实替代，决定后有真实代价”。

### 6. 有限季叙事需要总论断与单集推进相互校验

**直接来源支持（M6；SN-568、SN-576）**：Mazin 认为有终点的电视叙事可同时有整体问题与单集小问题；每集应有自身起中结与某种解决，并推进核心人物的长期问题。其 show bible 实践还区分“发生什么”与“为什么”。

**综合推断：** 把季弧视为“由集构成的圆”：每集明确其子论断/关系测试、人物状态改变及对季级问题的推进；若无法说明一集为什么必须存在，不能仅因其填满时长而保留。

## 工作流程

### 输入

- 项目的一句话外部 premise 与格式边界（电影/有限季/开放式连续剧）。
- 主角及关键关系的当前状态、可观察目标与已知限制。
- 拟定结尾或至少结尾必须回答的问题。
- 已有大纲、分集梗概或剧本（如有）。

### 流程 A｜建立论断—premise 对

1. 写出“发生什么”与“真正关于什么”。
2. 把后者改写成可争论命题；删除只是一词主题的表述。
3. 检验 premise 是否能自然、最好带反讽地把人物推向该命题的压力，而不是只提供热闹装置。
4. **输出：** 项目命题卡（premise、论断、反命题、终局待证明的行动）。

### 流程 B｜建立人物起点与终局测试

1. 写清主角的旧信念/盲点、恐惧、维持中的可接受不完美与当前目标。
2. 写清触发事件具体破坏哪一份平衡，并为何此人不能照旧处理。
3. 倒推终局：同一核心变量下，人物最终必须做出什么不同的、有代价的行动？
4. 设计在终局前仍可回到旧安全策略的诱惑或替代路径。
5. **输出：** 起点—低点—终局变化图；其中低点定义为旧路已失效、新路尚不能行动化，而非某一固定页码。

### 流程 C｜用因果与选择拆解剧情/分集

1. 对每个序列填写状态账本；优先连接“因为这个选择/后果，所以发生下一步”，而非“然后又发生”。
2. 每次主要冲突至少改变一个变量：认识、关系、策略、承诺、可选项或风险归属。
3. 对有限季剧集，同时标注：本集的小问题是什么？它怎样改变季级人物问题？
4. 场景层补充 POV：观众此处在情感上跟随谁？谁在体验、选择并承担后果？
5. **输出：** 可审计的因果链、分集推进表与场景状态账本。

### 流程 D｜把“为什么”写进协作文档

1. 每个 beat/场/集都分开写“发生什么”与“为什么此时发生”。
2. “为什么”至少回答：它测试哪一项信念/关系/目标？它强迫谁作何选择？它如何改变下一状态？
3. 在 show bible/季纲层记录角色拆解、总体主题讨论和关键创作选择，避免团队只继承事件表。
4. **输出：** 可供 writers’ room 讨论与审稿的“事件—理由—选择—后果”文档。

### 流程 E｜反模板审稿与返工

按以下顺序审查，而非先套页码：

1. 论断是否可争论，且与 premise 有内在连接？
2. 人物是否有可理解的旧逻辑、目标和真实选择？
3. 事件是否专门测试该人物，而不是对任何角色都一样有效？
4. 冲突和场景是否产生因果或状态变化？
5. 结局是否通过不同于开端的行动证明变化？
6. 若答案为否，回到最早失效的一层重建；根本性问题不以局部“补桥段”掩盖。

## 诊断问题

### 项目/季弧

1. 如果把主题词换成一句可反驳命题，故事究竟在检验什么？
2. 外部 premise 为什么恰好能迫使这个人物面对这项命题？
3. 故事的终点回答了开端提出的哪个核心问题？若无对应，终点是否只是停止？
4. 对有限季：总论断是什么？每集的小问题如何推进或反驳它？
5. “发生什么”以外，团队能否说清每一段为什么必须发生？

### 人物与关系

6. 主角当前相信什么旧逻辑？它带来什么短期安全，又造成什么代价？
7. 人物不知道什么、为何还看不见、什么压力或关系反馈才可能让他/她看见？
8. 人物此刻真正想要什么；这个欲望会如何被挑战、转向或加深？
9. 关键关系的推进是否由可见事件和选择造成，而非剧本预设它应该成立？
10. 这场戏/这集观众情感上与谁同行；该 POV 是否被有意选择？

### 场景、冲突与结尾

11. 本场的目的是什么：改变人物、暴露欲望/需要、还是让其失败？
12. 人物有哪些可行选项？实际选择是否像此时的这个人会作出的选择，而不是剧情便利？
13. 这次冲突后，哪项人物或关系变量实际改变？若没有，为什么不能删、并或重设？
14. 下一事件是否由前一事件/选择的后果产生，或至少明确地改变人物—主题位置？
15. 在终局处，旧路是否仍可选？最终行动是否比一句“我懂了”更能证明人物改变？

## 失败模式

| 失败模式 | 可见症状 | 证据基础 |
|---|---|---|
| 用主题名词代替论断 | 团队只说“关于家庭/权力”，却无法说明故事在主张什么 | 直接：SN-403、SN-483 |
| 先填节拍再塞人物 | 页码和转折都在，但人物为何改变无从解释 | 直接：SN-403、SN-502 |
| 人物是情节机关或旁观者 | 事件发生后人物只是被推到下一件事；选择可任意替换 | 直接：SN-307、SN-665 |
| 冲突重复而不改变状态 | 同类争执/威胁升级，人物策略、关系、知识和可选项均未变 | 直接：SN-060、SN-655 |
| 把变化写成解释 | 人物在对话里说出领悟，行动却仍遵循旧安全策略 | 直接：SN-403、SN-647 |
| 关系或结局跳步 | 关系因作者希望而成立；结尾与开端不相关 | 直接：PBS On Story、SN-423、SN-647 |
| 把框架变成新教条 | 强迫所有作品具有同一套 arc、页码或单一主题 | 直接：SN-403、SN-408；本方法的适用边界 |
| 在根本失配上做局部缝补 | 反复加戏仍无法回答项目为何存在、人物为何行动 | 直接：SN-216、SN-610；综合：返工顺序 |

## 修正方法

| 发现的问题 | 定向修正 | 可验证输出 |
|---|---|---|
| 主题模糊 | 将名词改写为可被角色行为检验的命题；重配 premise 与命题 | 命题卡能写出正反面及终局行动测试 |
| 中段无路可走 | 不补随机事件；重列人物旧信念、压力、怀疑、退回与新的代价 | 每个中段序列均有“压力—选择—后状态” |
| 主角被动 | 重设计事件，使其专门冲击主角的旧逻辑；列出至少两条可行路径 | 下一步由人物选择及其后果触发 |
| 冲突只是加量 | 合并重复冲突，或让冲突改变认识、关系、策略、承诺或可选项 | 状态账本无等价的连续重复行 |
| 终局无证明力 | 在旧安全路径仍可获得时，设计有代价的不同选择 | 起终能在同一核心变量上清楚对照 |
| bible 只有剧情简介 | 为每集/段增加“为什么、测试什么、谁选择、后果是什么”字段 | writers’ room 可以在不复述情节的情况下说明推进理由 |
| 返工越补越碎 | 回到 premise—论断—人物起点；必要时以新写作而非原稿缝补重建 | 新纲先通过前四项诊断，再进入场景修订 |

## 禁止继承

1. 禁止模仿 Craig Mazin 的措辞、口吻、个人幽默、人格、署名式理论语言或教学表演。
2. 禁止复用或影射其任何具体作品的情节、角色、对白、场景、视觉方案或独特表达。
3. 禁止把“central dramatic argument”当成必须让角色说出口的哲学口号；人物应通过目标、关系、选择和后果承载命题。
4. 禁止把本方法误称为适合所有形式的万能公式，或把“反模板”误读为拒绝大纲、生产规划或任何结构知识。
5. 禁止将本文件中的综合推断、工作表或诊断顺序伪造为 Craig Mazin 的直接引语或唯一标准。
6. 禁止用没有来源支撑的创作轶事、课程内容或作品解读补强权威感。

## 可 Skill 化规则

### 规则 1｜项目入口门

```text
IF premise 不能与可争论的中心论断相互解释
THEN 停止拆场；先重写 premise—论断配对
ELSE 进入人物状态设计
```

### 规则 2｜人物状态卡

```text
对每位核心人物记录：
旧信念/盲点 + 恐惧 + 当前目标 + 可接受的不完美 + 当前可选项
若缺少其中任一项，人物驱动性为“未验证”。
```

### 规则 3｜关键戏剧场景/序列状态机

```text
输入：前状态
施加：针对该人物的压力、信息或关系测试
要求：人物有真实选项并作出选择
输出：后果 + 至少一项状态变化
适用：关键戏剧场景或序列。

非选择型场景可以成立，但必须明确其功能：建立 POV、揭示需求、累积压力，
或改变观众掌握的信息；并说明它如何在相邻关键序列中产生可追踪影响。
若一个段落既没有选择，也没有上述功能或后续影响，才标记为“删除 / 合并 / 重新设计候选”。
```

### 规则 4｜有限季双层校验

```text
每集必须声明：本集小问题，以及至少一项可验证推进——人物、关系、知识、
策略、可选项或风险归属的变化；再说明它如何触及季级问题。
若刻意保持人物状态，须说明这份停滞如何构成压力或反讽，并在后续兑现。
若无法说明本集为何不可替换或删去，返回集级 premise 与人物测试重做。
```

### 规则 5｜结局证明门

```text
IF 终局只包含信息揭示、解释或口头领悟
THEN 未通过
IF 人物在旧路仍可得时作出有代价的新选择
AND 该选择与开端在同一核心变量上形成对照
THEN 通过“行动证明变化”检查
ELSE 标记为“终局证据不足/需返工”，列出缺失项（旧路不可见、代价不真实、
没有新选择、或未与开端同变量对照），并返回流程 B 的终局测试。
```

### 规则 6｜证据与推断门

```text
每一条方法主张必须标记：直接来源支持 / 综合推断。
直接来源支持：至少一份可核验一手材料；核心原则优先双来源交叉。
综合推断：列出所据来源编号，不得伪装成原话。
无来源且无法明确为推断：删除。
```
